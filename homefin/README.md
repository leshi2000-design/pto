# Домашняя бухгалтерия

Настольная программа (Python + PyQt6 + SQLite) для учёта личных финансов и коммунальных платежей.
Работает офлайн, данные лежат в `~/.homefin/homefin.db`, копия при каждом закрытии — в `~/.homefin/backups` (последние 20).

## Запуск

```
pip install -r requirements-homefin.txt
python run_homefin.py
```

## Что умеет

**Финансы**
- Несколько счетов (карта, наличные, вклад, кошелёк) с начальным остатком, переводы между ними.
- Доходы и расходы по категориям (свои категории, архив), примечания, поиск и фильтры по датам, счёту, категории, типу.
- Бюджеты: месячный лимит на категорию, индикатор расходования (зелёный / жёлтый от 80% / красный при превышении).
- Регулярные операции (зарплата, аренда, подписки): создаются сами, в том числе пропущенные, пока программа была закрыта.
- Отчёты за период: доходы/расходы, разбивка по категориям с долями, графики.

**Коммунальные платежи**
- Услуги (электричество, вода, газ, отопление и т. д. — свои можно добавлять), с единицей, лицевым счётом и фиксированной частью.
- Показания счётчиков с контролем (новое не может быть меньше предыдущего), расход считается автоматически.
- Тарифы с датой действия и порогом (льготный объём + повышенный тариф сверх него).
- Счёт на оплату считается сам по показаниям и тарифу либо вводится вручную; срок оплаты подставляется по прошлому счёту.
- «Оплатить» создаёт расход в категории «Коммунальные платежи» и списывает с выбранного счёта; оплату можно отменить.
- Напоминания о сроках и просрочке на вкладке «Обзор» и при запуске.
- Статистика начислений за 12 месяцев.

**Календарь**
- Месяц с цветными точками под числами: поступления, платежи, счета к оплате и плановые регулярные операции.
- По клику на день — список событий; прямо оттуда можно добавить операцию на эту дату или оплатить счёт.
- Итоги месяца: сколько пришло, ушло, осталось оплатить и что запланировано.

**Копилка**
- Цели накопления с суммой и сроком, индикатор прогресса и подсказка, сколько откладывать в месяц.
- Пополнение и снятие — переводы между вашими счетами и копилкой: общий остаток не меняется, а в доходах и расходах эти суммы не появляются.

**Пароль**
- «Счета и настройки» → «Пароль…»: вход по паролю при запуске, блокировка по Ctrl+L и автоблокировка при бездействии (по умолчанию 10 минут).
- Пароль хранится только в виде хэша (PBKDF2-SHA256 с солью). Восстановить забытый пароль нельзя.
- Важно: пароль закрывает вход в программу, но файл базы `homefin.db` не зашифрован.

**Прочее**
- Экспорт операций в CSV и Excel (с листом коммунальных счетов), импорт из CSV.
- Резервная копия и восстановление из копии, Ctrl+N — новая операция.
- Деньги хранятся в копейках (целые числа), без ошибок округления.

## Сборка .exe (Windows)

Запустите `build_exe_windows.bat` — получится один файл `dist\HomeFinance.exe`, Python на целевом компьютере не нужен.

## Оформление

Светлая тема в стиле ПТО: боковое меню, белые карточки, акцент `#1B6B62` (`theme.py`).

## Структура

- `core.py` — база и вся логика (без GUI, покрыта тестами `tests/test_homefin_core.py`)
- `exchange.py` — CSV/Excel, текстовый отчёт
- `gui.py` — интерфейс
- `money.py` — работа с суммами
- `theme.py` — светлое оформление
- `gui_extra.py` — календарь, копилка, пароль
- `assets/` — логотип (`logo.svg`, `icon.png`, `icon.ico`; пересборка — `assets/make_icons.py`)

Тесты: `QT_QPA_PLATFORM=offscreen python -m pytest tests/test_homefin_*.py --noconftest`
(`--noconftest` нужен, потому что общий `tests/conftest.py` относится к другому проекту в этом репозитории).
