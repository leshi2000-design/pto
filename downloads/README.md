# Магазин 2

Скачайте [Magazin.zip](Magazin.zip?raw=true) и распакуйте архив целиком.

В Windows установите Python 3.12 с Python Launcher. Для одного компьютера: `start_shop_windows.bat`. Для сети: `start_shop_server_windows.bat` на сервере и `start_shop_client_windows.bat` у сотрудников. Первый запуск требует интернет. Это исходники, не Windows EXE; реальная Windows-сеть ещё не проверена.

Инструкция находится в архиве: `README.txt` и `docs/MAGAZIN_GUIDE_RU.md`. Программа использует свою базу `shop.db` и не изменяет данные СМЕТА-ГАЗ.

![Интерфейс Магазина с демонстрационными данными](Magazin-interface.png)

Добавлены склад, розничные цены, счета с резервированием, оплаты, долги после передачи, FIFO-маржа, календарь, белорусские реквизиты и клиент-серверный режим. Исправлено закрытие SQLite-подключений бекапа и повторное закрытие окна.

Проверки: 23 теста Магазина, 13 разделов интерфейса, два клиента и конкурентное резервирование последнего товара. Общая проверка: 136 тестов прошли. Доступ пока по общему ключу, без отдельных ролей. Инструкция включает сеть и HTTPS.
