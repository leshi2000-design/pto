# Группы товаров

Группа — именованный набор позиций справочника (материалов и работ). Например, группа «ГСВ» содержит всё, что обычно идёт в смету по газоснабжению. В смете группа добавляется одним действием: позиции подставляются сами, остаётся указать количество, лишнее убрать.

## Создание группы
1. «Справочник» → вкладка **«Группы товаров»**.
2. **«Создать группу»** (например, «ГСВ») → **«Добавить из справочника…»**: поиск по названию, можно выбрать сразу много позиций (Ctrl/Shift), фильтр «только материалы» / «только работы».
3. Количество **по умолчанию** меняется двойным щелчком в колонке «Кол-во по умолчанию» (по умолчанию 1). Порядок позиций — кнопками «Вверх» / «Вниз»; «Убрать из группы» не удаляет саму позицию из справочника.
4. Быстрее всего: в обычном справочнике выделите позиции, правый щелчок → **«Добавить в группу товаров…»** (можно тут же создать новую группу).
5. «Копировать» делает копию группы (удобно для вариантов вроде «ГСВ — врезка»), «Переименовать», «Удалить группу» (позиции справочника и готовые сметы не затрагиваются).

## В смете
В редакторе сметы кнопка **«Группа товаров»**:
- выберите группу; в таблице уже все её позиции с актуальными ценами справочника;
- укажите **количество** у нужных, у лишних уберите галочку или поставьте 0 — такие позиции в смету не попадут;
- справа вверху — **куда положить**: в существующий раздел сметы, в конец сметы или в **новый раздел** с названием группы (так предлагается по умолчанию; если раздел «ГСВ» в смете уже есть, предлагается он);
- «Добавить в смету» — позиции добавляются как обычные строки: цены и состав стоимости работ запоминаются в смете (позднее изменение цены в справочнике старую смету не меняет). Дальше их можно править, переносить между разделами и удалять как любые другие.

## Что важно
- Цена берётся из справочника **в момент добавления группы**, а не в момент создания группы.
- Если позиция удалена из справочника, она сама исчезает из всех групп.
- Название группы уникально (без учёта регистра).
- В сетевом режиме группы общие для всех сотрудников.
