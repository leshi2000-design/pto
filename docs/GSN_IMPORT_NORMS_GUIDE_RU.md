# Импорт договоров Монтаж ГСВ, нормы расхода, оформление (версия 3.4)

## Импорт договоров «Монтаж ГСВ» из Excel
**Монтаж ГСВ → «Импорт из Excel…».** Выберите файл: столбцы подбираются по названиям (строка заголовков ищется сама, над таблицей могут быть лишние строки), любой столбец можно перепривязать вручную.

| Столбец | Куда попадает |
|---|---|
| № договора | номер договора (по нему определяется, есть ли договор в программе); если пусто — присваивается следующий «NN-02/ГГ». Без номера «тот же» договор определяется по заказчику, адресу и дате |
| Адрес | адрес объекта (и адрес нового клиента, если у него адреса нет); название объекта берётся из адреса, если нет столбца «Объект» |
| Заказчик, Телефон, Паспортные данные | клиент в «Клиентах» (существующий клиент с таким ФИО дополняется, заполненное не затирается) |
| Дата заключения, Стоимость | дата и сумма договора (договор отмечается подписанным, срок окончания работ ставится по умолчанию) |
| ДАТА АКТА | дата акта (акт отмечается подписанным); видна в карточке, реестре, календаре и ведомости актов |
| Проект | шифр проекта в карточке договора |
| ПГ-4, Котел, Счетчик, Сигнализатор, Регулятор | оборудование договора (вкладка «Оборудование»): отметка («+», «да», «1») — одна запись, число — столько записей, текст — модель (например «Бош») |

Перед импортом показывается проверка (новые, уже есть, ошибки — например, нет заказчика или номер повторяется) и создаётся резервная копия базы. Если договор с таким номером есть, его можно пропустить или обновить (оборудование тех видов, чьи столбцы импортируются, заменяется).

## Справочник норм и расход материалов по стыкам
1. **Списание → «Справочник норм»**: для каждой нормы (по умолчанию заготовки Ду 15, 20, 25, 32) вручную введите расход каждого материала **на один стык**. «Пусто» — норма не задана, «0» — материал не расходуется. В списке видно, сколько норм заполнено; есть кнопка «Копировать норму».
2. **Монтаж ГСВ → «Трубопроводы и стыки»**: введите количество стыков. Столбец «Норма расхода» подбирается автоматически по диаметру из названия трубопровода (можно выбрать другую норму из справочника).
3. Ниже таблицы **автоматически** появляется «Расход материалов на объект» — стыки × норма по каждому материалу. Не найденные или не заполненные нормы показываются предупреждениями. Кнопка «Выгрузить расход в Excel…» сохраняет итог и расчёт по каждому стыку.
Расход, записанный в график работ, по-прежнему виден в окне «Расход строительных материалов».

## Оформление
Современный минималистичный стиль (светлая и тёмная темы): мягкие нейтральные цвета, скругления, плоские кнопки, тонкие разделители, один акцентный цвет (индиго; свой цвет задаётся в «Настройках»). Шрифт не мельче 10 пт, контраст основного текста не ниже WCAG AA. Боковое меню — разделы без деревьев, выбранный пункт выделен мягкой «таблеткой».
