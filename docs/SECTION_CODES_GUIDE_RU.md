# Номера разделов договоров

В номере договора «07-02/26» число **02** — номер раздела (вид договора), 07 — порядковый номер в году, 26 — год. Раньше разделы были заданы жёстко (02 — монтаж ГСВ, 03 — проекты ГСВ, 04–07 — юрлица, СМР, ТО, ИП). Теперь номер раздела для каждого вида договора задаётся вручную.

**Где:** «Настройки» → **«Номера разделов договоров»**.

| Вид договора | Где создаётся | По умолчанию |
|---|---|---|
| Договор на монтаж ГСВ | «Монтаж ГСВ» | 02 |
| Договор на проект ГСВ | «Проекты ГСВ» | 03 |
| Прочие договоры юрлиц | «Справочник юрлиц» | 04 |
| Договор на СМР (юр. лица) | «СМР (юрлица)» | 05 |
| Договор на ТО (юр. лица) | «ТО (юрлица)» | 06 |
| Договор на СМР (физ. лица) | «СМР (ИП)» | 07 |

- Впишите нужные номера (1–4 знака: цифры или буквы, без пробела, дефиса и «/») и нажмите «Сохранить номера разделов». В таблице сразу виден пример следующего номера и сколько договоров уже создано с этим номером.
- Номера разделов **разных видов не должны совпадать**, иначе по номеру нельзя понять вид договора. Программа это проверяет, в том числе с прежними номерами (по ним уже созданы договоры).
- Меняются **только новые договоры**. Старые остаются как были и по-прежнему узнаются программой (например, при обмене номерами и резерве). Порядковый номер в году продолжается: после «05-02/26» при смене раздела на «12» следующим будет «06-12/26».
- Подпись «XX-12/26 (авто)» в новой карточке и подсказка при изменении номера тоже показывают действующий номер раздела.
- Проектный номер «07-26 ГСВ» от номера раздела не зависит.
- В сети настройка общая для всех сотрудников.
