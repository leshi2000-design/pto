# Версия 3.6: журнал и корзина, защита данных, выборки и колонки, фоновые операции

## Журнал и корзина (Дополнительно → «Журнал и корзина»)
- Программа записывает создание, изменение и удаление записей в основных реестрах: договоры (Монтаж ГСВ, Монтаж ГСН, Юрлица, СМР), проекты ГСВ, сметы, оплаты, клиенты, юрлица, заметки, задачи, сварщики, списания и вложенные записи (оборудование, трубопроводы, стыки). Служебные поля (например, пересчёт сметы) в журнал не попадают.
- «Что изменилось…» показывает поля «было → стало»; для удалённой записи — все её данные.
- **Корзина:** фильтр «Только удалённые (корзина)» → «Восстановить». Запись возвращается с тем же номером вместе с вложенными записями, удалёнными одновременно с ней. Если запись с таким номером уже есть, восстановление не выполняется.
- Журнал хранится 400 дней. Он находится внутри базы и входит в резервные копии.
- Удаление по-прежнему окончательное для вложенных **файлов** на диске: журнал хранит данные записей, но не сами файлы.

## Защита данных
- **Пароль внешних копий** больше не хранится в настройках открытым текстом. В Windows он защищён средствами системы (DPAPI) и читается только тем же пользователем Windows на этом компьютере; в других системах — шифрованием с ключом из файла `secret.key` рядом с базой. Обычные копии базы (ZIP) пароля не содержат вовсе. При переносе базы на другой компьютер или другого пользователя пароль нужно ввести заново (это ожидаемо).
- **Шифрование самой базы на диске.** Встроенное шифрование SQLite (SQLCipher) в программу не добавлялось: оно требует отдельной сборки библиотеки, усложняет обновления и при потере ключа делает данные недоступными. Рекомендуемое решение — **шифрование диска средствами Windows (BitLocker или шифрование папки `.smetagaz`)** и вход в программу по паролю («Настройки»). Копии вне компьютера шифруются отдельно (AES-GCM).

## Выборки, поиск и колонки в реестрах
- Реестры «Проекты ГСВ», «Монтаж ГСВ», «Монтаж ГСН», «Юрлица», «СМР» получили кнопки **«Выборки ▾»** и **«Колонки ▾»** (колонки также настраиваются правым щелчком по заголовку таблицы).
- **Выборка** — сохранённый поиск под своим именем; хранится в программе и доступна в один щелчок.
- **Поиск** понимает несколько слов («иванов минск»: слова ищутся независимо, в любых полях — номер, клиент, объект, адрес) и **телефон в любом написании** («29 111», «+375 (29) 111-22-33»). Поиск по клиентам учитывает адрес.
- Скрытые колонки запоминаются для каждого реестра отдельно; скрыть все колонки нельзя.

## Фоновые операции
Резервные копии (ручные, внешние, проверка и восстановление), выгрузка реестров в Excel, проверка целостности базы и импорт из Excel выполняются в фоне: окно прогресса с кнопкой **«Отмена»**, программа не «зависает».
- Отмена копии безопасна: итоговый файл заменяется только после успешного завершения, прежний остаётся нетронутым.
- Отмена импорта оставляет уже загруженные строки (перед импортом всегда делается снимок базы).
- Проверка целостности — только чтение; её отмена просто прекращает ожидание.
