# ПТО 4.19.0 — сортировка договоров с юрлицами

В реестрах **СМР (юрлица), ТО (юрлица) и Прочие (юр.лица)**, рядом с фильтрами, появилась настройка сортировки:
* список **«По номеру договора / По дате заключения / По статусу»** и кнопка направления **«▲ по возрастанию / ▼ по убыванию»**;
* то же можно сделать **щелчком по заголовку колонки** «№ договора», «Дата», «Статус» (повторный щелчок меняет направление; стрелка в заголовке показывает текущую сортировку);
* выбор **запоминается отдельно для каждого раздела** и сохраняется после перезапуска.

Как сортируется:
* **по номеру** — по году и порядковому номеру, а не по тексту: 02-05/26, 05-05/26, 10-05/26 (а не 10 раньше 2), затем договоры 2027 года;
* **по дате заключения** — договоры без даты всегда в конце списка, при любом направлении;
* **по статусу** — по визуальному статусу в порядке: Предварительно, В работе, Просрочен, Годовой, Завершён, Расторгнут (с учётом статуса, проставленного вручную); внутри одного статуса — по номеру.

**В веб-клиенте** у списков этих же разделов над таблицей — кнопки «Сортировка: Номер / Дата заключения / Статус» (нажатие на активную меняет направление); по умолчанию берётся сортировка, сохранённая в программе, а если её нет — новые договоры сверху, как раньше.

Порядок списка по умолчанию в программе не изменился (по номеру, по возрастанию). СМР (ИП) и СМР (физлица) не менялись.
