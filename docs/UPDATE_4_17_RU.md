# ПТО 4.17.0 — выделение НДС в смете; проверка работы в фоне

## 1. Выделить НДС из суммы
В окне сметы, блок **«НДС»**: галочка «Начислять НДС», ставка и список способов:
1. **Начислить сверху на всю смету** — позиции без НДС, НДС на итог;
2. **Начислить сверху на каждую позицию** — колонки «НДС» и «Сумма с НДС», итог = сумма позиций с НДС;
3. **Выделить НДС из суммы каждой позиции** *(новое)* — введённая сумма **уже содержит НДС**: в строке показано «в т. ч. НДС» (сумма × ставка / (100 + ставка), например 100 руб при 20 % → 16,67) и «Без НДС» (83,33); **итог сметы не меняется**;
4. **Выделить НДС из итога сметы** *(новое)* — итог не меняется, внизу показаны «Итого без НДС» и «в том числе НДС».
Скидки/наценки сметы действуют до выделения. Маржа считается без НДС. PDF и Excel сметы показывают «в т. ч. НДС» / «Без НДС» (в строках) и «в том числе НДС» (в итогах). Новые теги шаблонов: `{vat_extracted}` (НДС выделен: Да/Нет), в таблице позиций — `amount_net`; прежние `{ндс}`, `{итого_без_ндс}`, `{ндс_процент}` работают во всех режимах.

## 2. Работа в фоне — проверена «по-настоящему»
Добавлен автоматический тест, который запускает настоящую программу с ключом `--background` и проверяет: окно при запуске не показывается, а веб-доступ уже отвечает; второй запуск программы открывает окно первой и сам завершается; крестик сворачивает окно, а веб-доступ продолжает отвечать; «Выход» из значка завершает программу без зависания, после чего сайт не отвечает. Значок у часов в тестовой среде подменён (его там нет), поэтому проверка самого значка, реестра Windows (автозапуск) и поведения при выключении Windows остаётся за вашей проверкой на компьютере.
