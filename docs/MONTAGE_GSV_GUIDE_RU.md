# Раздел «Монтаж ГСВ» (версия 2.6)

Раздел самостоятелен: общим с другими разделами у него только клиент из модуля «Клиенты». Карточка договора не связана с модулем «Исполнительная документация» — у монтажа ГСВ своя исполнительная документация внутри карточки.

## Вкладка «Договор и клиент»

- **Номер договора** формируется сам: `01-02/26` — порядковый номер, раздел 02 (монтаж ГСВ), год заключения. Старые договоры сохраняют свои номера.
- **Объект:** наименование (по проекту и ТУ) и адрес объекта.
- **Клиент:** ФИО, несколько телефонов с пояснениями, адрес, паспорт, кем выдан, дата выдачи. Клиент попадает в «Клиенты»; кнопка «Выбрать из «Клиенты»…» подставляет существующего. Если ФИО уже есть в базе, программа предложит подставить сохранённые данные.
- **Проект:** шифр проекта, проектировщик, месяц и год проекта.
- **Сроки и стоимость:** начало работ = дата заключения (флажок «Договор подписан»); окончание по умолчанию через 60 дней, можно ввести вручную; дата акта и флажок «Акт подписан» (пока акт не подписан, работа считается не сданной); стоимость вводится вручную или берётся из сметы.
- Первое сохранение: поля открыты, затем программа предлагает **создать новую папку или привязать существующую**. Имя новой папки: `01-02.26, адрес объекта (Фамилия И.О.)`. Позже карточка открывается закрытой, поля разблокирует кнопка «Изменить».
- Договор отмечается в календаре («Заключение договора Иванов И.И.»).

### Смета
- Нет сметы: «Нет данных». Кнопки «Создать смету» и «Привязать смету».
- Смета привязана, данные не получены: «Получить данные из сметы» — кнопка «Получить стоимость из сметы». После неё показаны стоимость материалов и стоимость работ по клиенту, итог по смете становится стоимостью работ договора.
- Если смету потом изменили: «Смета была изменена — обновите данные». «История изменений сметы» показывает журнал: что добавлено, удалено, изменено (кол-во, цена, сумма) и когда. Журнал ведётся с момента обновления до 2.6.
- Кнопка «Сформировать смету…» открывает выгрузку сметы; шаблон и теги сметы настраиваются в модуле смет.

### Документы по тегам
Договор на монтаж, акт выполненных работ и справка о стоимости, карточка клиента с оплатами (Excel; на каждую оплату добавляются свои столбцы). Если после создания данные изменились, документ получает пометку «данные изменились» и кнопку «⟳ Переформировать». Для создания нужна папка договора.

## Вкладка «Оборудование»
Таблица: оборудование (ПГ, котёл, счётчик газа, регулятор давления газа, сигнализатор, колонка или тип, введённый вручную), тип / модель, серийный номер, примечание и файл паспорта или сертификата. Файл копируется в подпапку «Оборудование» папки договора.

## Вкладка «Трубопроводы и стыки»
- **Трубопроводы:** наименование из справочника ГСВ, количество в метрах (2 знака), сертификат подтягивается из справочника, примечание. Кнопка «Взять данные из сметы» подбирает позиции сметы с тем же наименованием, что и в справочнике. Строки, взятые из сметы, обновляются при изменении сметы; ручное изменение количества отвязывает строку.
- **Стыки:** строки повторяют верхнюю таблицу; вводится количество стыков и примечание. Итог выводится текстом. «Добавить произвольный стык» — тип и диаметр трубы, которых нет в справочнике (остаётся только в нижней таблице). Названия и количества можно править, строку можно удалить.
- **Внести в график работ…:** объект, дата, трубопроводы и стыки подставляются сами, сварщик выбирается из модуля «Сварщики». Кнопка «Расход материалов» считает расход по нормам модуля «Списание» (количество стыков × норма); для каждой строки выбирается норма (по диаметру подбирается автоматически). После «Сохранить» запись попадает в график и в календарь, расход сохраняется в карточке: кнопка «Расход материалов» внизу.

## Вкладка «Исполнительная документация»
1. **Сертификаты:** оборудования (из вкладки оборудования), трубопроводов (из справочника ГСВ), зависимые, по умолчанию, произвольные. Открыть, напечатать (системное окно), убрать из списка, вернуть убранные, пакетная печать. Кнопка «Зависимости и сертификаты по умолчанию…» (она же есть в «Справочниках ГСВ») задаёт правила для всей программы: «если в объекте есть сигнализатор — добавить сертификат производителя», «если в названии трубы есть 32 или название производителя — добавить сертификат деталей». Сами файлы не копируются: в карточке хранится путь.
2. **Документы:** Реестр ГСВ, гарантийный паспорт, акт приёмки в эксплуатацию, строительный паспорт, акты скрытых работ, акт ревизии тех. устройств, акт о проведении ревизии оборудования. Каждый можно сформировать (в папке договора), привязать готовый файл, открыть, напечатать, удалить, переформировать; есть «Сформировать все» и «Печать всех».
3. **Аттестаты:** выбор аттестатов, протоколов и других документов из модуля «Сварщики», открытие и печать.

## Вкладка «Шаблоны и теги»
- **Шаблоны документов:** файл Word или Excel для каждого из 10 документов; без выбора используется простая стандартная заготовка. Для боевых документов привяжите свои шаблоны.
- **Редактор тегов:** у каждого тега — имя, источник данных (поле карточки, оборудование, трубопровод), формат (дата «12 ноября 2026», «12» ноября 2026, 12.11.2026, месяц, деньги, сумма прописью, число с двумя знаками, заглавными) и текст «если данных нет». Теги можно переименовать, отключить, создать новые. Теги оборудования и каждого трубопровода справочника создаются автоматически и дают пустое значение, если оборудование или труба в объекте не используются.

Основные теги: `{НОМЕР_ДОГОВОРА}` `{ДАТА_ДОГОВОРА}` `{КЛИЕНТ}` `{КЛИЕНТ_СОКР}` `{ПАСПОРТ}` `{ДАТА_ВЫДАЧИ}` `{КЕМ_ВЫДАН}` `{ОБЪЕКТ}` `{АДРЕС}` `{НАЧАЛО_РАБОТ}` `{ОКОНЧАНИЕ_РАБОТ}` `{СТОИМОСТЬ}` `{СТОИМОСТЬ_ПРОПИСЬЮ}` `{ТЕЛЕФОН}` `{МЕСЯЦ_РАБОТ}` `{ДАТА_АКТА}` `{НОМЕР_ПРОЕКТА}` `{ПРОЕКТИРОВЩИК}` `{ДАТА_ПРОЕКТА}`; оборудование — `{КОТЕЛ_МОДЕЛЬ}` `{КОТЕЛ_СЕРИЙНЫЙ_НОМЕР}` и т. д.; трубопроводы — `{ТРУБОПРОВОД_…}`, сокращённые `{ТРУБА_32}`, `{ДЛИНА_32}`, `{СТЫКИ_32}`.

## Выгрузка в Excel
Раз в час перезаписывается `excel_reports/Реестры_договоров.xlsx` (лист «ГСВ» — монтаж ГСВ со всеми полями карточки, лист «ГСН»).

## Обновление существующих баз
Оборудование и трубопроводы, внесённые в договоры прежними версиями, переносятся в новые таблицы один раз. Ранее внесённые договоры считаются подписанными; папка, привязанная в общем модуле, становится папкой договора. Модуль «Исполнительная документация» остаётся как был, но данные монтажа ГСВ больше туда не попадают.
