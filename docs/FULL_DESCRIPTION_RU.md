# ПТО — полное описание функционала (версия 4.5)

Настольная программа для организации, занятой газификацией и строительно-монтажными работами: договоры и акты, сметы, клиенты и юрлица, исполнительная документация, склад материалов, сотрудники, налог ИП, сетевая работа нескольких компьютеров.

- **Платформа:** Windows (проверялась сборка из исходников на Python 3.11/3.12), интерфейс на PyQt6, данные в SQLite.
- **Где данные:** папка `.smetagaz` в домашней папке пользователя (две базы: `smetagaz.db` и `clients.db`, плюс папки `projects`, `templates`, `attachments`, `backups`, `incoming`, `excel_reports`). Не зависят от папки программы.
- **Что не делает:** программа не отправляет данные на внешние серверы. Сеть используется только для: проверки обновлений (если вы вписали адрес), чтения цен по ссылкам на товары (по кнопке), обмена с вашим собственным «ПТО Сервером» в офисе.

---

## 1. Общие принципы работы

### 1.1. Окно и навигация
Слева боковое меню с разделами, справа рабочая область. Разделы меню разделены линиями; названия и видимость разделов настраиваются («Настройки → Внешний вид»). Две темы (светлая/тёмная), шрифт и акцентный цвет, значки в стиле Microsoft Office. Страница с кнопкой «?» и клавиша **F1** открывают справку по текущему разделу.

### 1.2. Горячие клавиши
| Клавиши | Действие |
|---|---|
| Ctrl+K | глобальный поиск по всем реестрам |
| Ctrl+N | создать запись в текущем разделе (договор, смету, клиента…) |
| Ctrl+S | сохранить в открытой карточке |
| Ctrl+F | перейти в строку поиска раздела |
| F1 | справка по разделу |

### 1.3. Реестры (таблицы)
- Поиск понимает несколько слов, регистр и телефон в любом написании.
- **Выборки ▾** — сохранить текущий поиск/фильтр под именем; **Колонки ▾** (или правый щелчок по заголовку) — скрыть/показать колонки; SQL-фильтры по колонкам.
- Постраничный вывод (по 200 записей) — реестр открывается быстро и при тысячах записей (проверено на 10 000).
- Сортировка по номеру и дате договоров; порядковых номеров строк нет.
- Двойной щелчок открывает карточку; правый щелчок — действия над записью.

### 1.4. Даты и ввод
Во всех полях дата в формате дд.мм.гггг, по умолчанию сегодня; можно вводить цифрами (14102026) или выбирать в календаре.

### 1.5. Фоновые операции
Копии, выгрузки, проверки, импорт и распознавание идут в фоне с окном прогресса и кнопкой «Отмена». Закрытие программы не зависает: окно скрывается сразу, нужная копия делается в фоне.

### 1.6. Глобальный поиск (Ctrl+K)
Полнотекстовый поиск (по словам и их началу, устойчивый к регистру и ё) по клиентам, сметам, договорам всех разделов, проектам ГСВ/ГСН, материалам и справочникам, сертификатам, задачам и событиям, файлам, сварщикам, списаниям и нормам, юрлицам, актам и заметкам. Двойной щелчок открывает карточку.

### 1.7. Защита и целостность
- Необязательный пароль на вход в программу (хранится как хэш scrypt, не короче 10 символов; после неудачных попыток вход блокируется).
- Журнал ошибок, журнал изменений и корзина, проверка целостности базы, автоматические и страховочные копии (подробнее — разделы 4, 9, 10).

## 3. Разделы подробно

### 3.1. Сегодня
Стартовый экран.
- **Доска задач** (колонки-статусы), задачи перетаскиваются мышью между колонками, порядок внутри колонки задаётся вручную, есть сортировка «Вручную». Свои статусы, теги и важность («Теги и статусы»).
- **Быстрое добавление** одной строкой: «Сдать акт Иванова завтра #акт !» — срок (завтра, в пятницу, через 3 дня, до 10-го, 15.10), тег (#акт) и важность (! — высокая, !! — критическая) распознаются сами.
- **«💡 Предложения»** — автозадачи из договоров и актов (отметить нужные и создать, остальные скрыть).
- **Календарь** (сворачивается; выбор запоминается): графически отмечены задачи со сроком, договоры, акты, оплаты, плановые работы сварки, допуски сотрудников, назначения бригад, ежемесячные даты (зарплата, налоги и т. п.) и заметки.
- **Список дня** и **заметки** с привязкой к клиенту, юрлицу или договору.
- Просроченное подсвечивается.

### 3.2. Проекты ГСВ
Реестр проектов по номеру ПД (проектной документации).
- **Новый проект ПД** — создаётся карточка, номера присваиваются сами: проект `07-26 ГСВ`, договор `07-03/26` (раздел 03 — настраивается, см. 7.3). Сначала выбирается/создаётся заказчик (клиент или юрлицо), затем остальное.
- Карточка «Договор и клиент»: объект, адрес, заказчик, несколько телефонов с пояснениями, стоимость, срок исполнения (по умолчанию 30 дней), технические условия, подписание договора и акта (без подписанного акта работа считается не сданной), примечания.
- **Статусы работы и клиента** — свои, редактируемые, можно отмечать несколько; в реестре отображаются.
- **Документы по шаблонам Word/Excel** (договор, акт, карточка и др.) с тегами `{{ТЕГ}}`; пометка «нужно переформировать» после изменения данных; вкладка «Шаблоны и теги» с редактором.
- **Импорт из Excel** (сопоставление колонок, предпросмотр), **выгрузка в Excel**, **ведомость подписанных актов** за месяц для бухгалтерии (в Excel, PDF).
- Оплаты, файлы клиента, календарь. Карточка заблокирована от случайной правки до нажатия «Редактировать».
- Резерв номеров: создание пустых карточек «под резерв» с подряд идущими номерами; обмен номерами между карточками; ручная смена номера (при занятом номере программа предлагает поменяться).
- Печать и PDF карточки и реестра одной кнопкой.

### 3.3. Монтаж ГСВ
Договоры на монтаж газоснабжения в жилом доме.
- Номер вида `01-02/26` (порядок-раздел/год); раздел 02 настраивается (7.3). Автонумерация, в новой карточке подпись «XX-02/26 (авто)».
- **Заказчик:** физлицо (из «Клиентов») или юрлицо (из «Справочника юрлиц»); при совпадении ФИО программа предлагает существующего клиента.
- **Пять вкладок карточки:**
  1. *Договор и клиент* — данные договора, паспорт, объект, сроки, стоимость, НДС, смета и её история, статусы работы/клиента, передача исполнительной документации (кому и когда), оплаты.
  2. *Оборудование* — котёл, счётчик, сигнализатор, регулятор и др. с файлами паспортов.
  3. *Трубопроводы и стыки* — длины, диаметры, стыки с записью сварщиков; введите количество стыков — **расход материалов считается автоматически** по справочнику норм («Списание»).
  4. *Исполнительная документация* — сертификаты (зависимые от материалов и «по умолчанию»), аттестаты, документы.
  5. *Шаблоны и теги* — шаблоны Word/Excel этого раздела и редактор тегов.
- Формирование документов по шаблонам с сохранением форматирования (посимвольное сохранение прогонов Word; колонтитулы и таблицы тоже заполняются).
- Работа с папкой договора на диске (создание, привязка, имя «01-02.26, адрес (Фамилия И.О.)»).
- Импорт из Excel (№ договора, адрес, заказчик, телефон, паспорт, дата, стоимость, дата акта, проект, ПГ-4, котёл, счётчик, сигнализатор, регулятор), ведомость актов, оплаты, календарь, сверка данных перед формированием документов.

### 3.4. Монтаж ГСН
Отдельный модуль наружного газоснабжения; общее с остальными разделами только «Клиенты» и «Сметы». Заказчик — физлицо.
- **Четыре вкладки:** *Договор и клиент* (объект, клиент, проект, сроки и стоимость, смета; окончание работ по умолчанию = дата заключения + 60 дней; «Акт подписан»); *Трубопроводы и оборудование* (длины ПЭ 32 и стали 25, тип газопровода, врезка в сталь/ПЭ, муфты; сертификаты и аттестаты по умолчанию и зависимые); *Исполнительная документация*; *Шаблоны и теги*.
- **14 документов:** договор, титульник, реестр исполнительной документации, гарантийный паспорт, справка об оплате, акт приёмки объекта в эксплуатацию, строительный паспорт, акт на скрытые работы, акт ревизии технических устройств, протоколы ВКК (ввод, муфта, труба, неразъёмное соединение), акт передачи материалов.
- Свой справочник ГСН (позиции, сертификаты, роли и правила аттестатов); импорт норм и позиций из Excel.
- Выгрузка, ведомость актов, оплаты, календарь, печать/PDF карточки.

### 3.5. СМР (ИП)
Индивидуальный предприниматель (договоры с физлицами и работы без договора); связан только с клиентами и сметами.
- **Вкладки:** *Договоры*, *Акты*, *Сметы* (в том числе без договора), *Оплаты* (клиент просто рассчитался без договора), *Ведомость по месяцам*, *Налог*, *Шаблоны и теги*.
- **Ручной клиент:** в сметах и оплатах можно ввести клиента вручную (ФИО, телефон) без создания карточки заранее.
- **Ведомость по месяцам** — выполненные работы (подписанные акты и сметы без договора) и оплаты; Excel, PDF, печать.
- **Налог:** база = выручка − 20 % − вычет на бедность (216 BYN, если выручка за месяц ≤ 1308 BYN) − вычеты на детей (120) и иждивенцев (63); налог = база × 20 %. Значения вычетов задаются вручную в начале года. Расчёт по кварталам и итог за год.
- **Ручные данные для налога:** суммы выручки за 1–2 кварталы 2026 (когда договоров и актов в программе ещё не было): вводятся за квартал или по месяцам, складываются с оплатами из программы; вводится и уже уплаченный налог — виден остаток к уплате.

### 3.6. Реестр смет
- Смета создаётся под клиента (без договора); договор привязывается позже. Можно создать смету под **произвольного клиента, введя его вручную**.
- **Редактор сметы:** позиции из справочника (материалы и работы с деревом разделов справочника), произвольные позиции, **разделы сметы** (ГСВ, ГСН, СМР, ТО, ДВК и свои), перенос позиции в раздел правым щелчком, подитоги по разделам, количество, цена, закупочная цена.
- **Группы товаров:** кнопка «Группа товаров» подставляет сразу все позиции выбранной группы (например, «ГСВ») с актуальными ценами; остаётся указать количество и убрать лишнее; группу можно положить в существующий или новый раздел сметы.
- **Оплаты прямо в смете:** панель «Оплаты по смете» (дата, сумма, примечание, «Остаток», удаление ошибочной), итог «оплачено / остаток».
- Начислений на работы нет — они уже входят в цену работ справочника. Состав стоимости работ (часы, ставка, накладные, прибыль, прочее) запоминается в строке.
- **«Расшифровка и маржа»** — одно окно (закупка, продажа, маржа) с экспортом по шаблону.
- Экспорт сметы: Excel (в том числе по шаблону) и PDF; карточка клиента — Word и PDF.
- Привязка к договорам разных разделов (монтаж ГСВ, ГСН, СМР, ТО, ИП), статусы, папки.
- Вкладка «Шаблоны и теги» — шаблоны и русские теги смет. Редактор блокируется, если смету открыл другой сотрудник (сеть).

### 3.7. Клиенты и досье клиента
- Реестр физлиц (ФИО, телефоны, адрес, паспорт, примечания); поиск по телефону и адресу; общая база для всех разделов (создание клиента из любой карточки).
- **Досье клиента** (двойной щелчок): вкладки *Договоры* (все разделы), *Сметы*, *Чеки* (продажа по чеку без сметы), *Оплаты*, *Заметки*, *Задачи*, *Файлы*. PDF-карточка клиента.
- Удаление клиента делает страховочный снимок базы.

### 3.8. Справочник юрлиц
- Все организации: краткое и полное наименование, УНП, ОКПО, юридический и почтовый адреса, банк, БИК, расчётный счёт, руководитель (и в родительном падеже для договоров), основание, контактные лица.
- **Реестр банков** (название, БИК, адрес): выбранный банк подставляет реквизиты в документы; изменение банка обновляет реквизиты всех юрлиц, использующих его.
- **Досье юрлица** (двойной щелчок): все договоры (проекты и монтаж ГСВ, СМР, ТО, прочие), оплаты, сметы, продажи по чеку, заметки, файлы, а также вкладка исходящих документов.
- Договоры «прочие» с направлением (входящий/исходящий), предметом, суммой, статусом; акты; исходящие документы с регистрационным номером.

### 3.9. СМР (юрлица) и ТО (юрлица)
Два отдельных раздела со своей нумерацией (по умолчанию NN-05/ГГ и NN-06/ГГ), шаблонами и тегами.
- Договор с юрлицом из справочника, акты, справки о стоимости выполненных работ, смета, оплаты, ведомость актов.
- Документы по шаблонам Word/Excel; теги по полям договора, организации, банку; форматирование шаблона сохраняется.
- Календарь сроков, привязанные папки и файлы, печать/PDF.

### 3.10. Сварщики
Сварщики, их аттестаты, сварочные документы (с номером, видом, сроками) и **график производства работ**: «Запланировать работы» — запись на будущую дату и адрес (появляется в календаре «Сегодня» как плановые работы); «Отметить выполненными»; непроставленный прошедший план подсвечивается красным. Колонки подстраиваются под содержимое.

### 3.11. Списание (склад материалов)
- **Материалы и остатки** с историей поступлений и списаний (двойной щелчок — карточка движения). Контроль отрицательных остатков по датам.
- **Акты списания** (проведение, сторнирование, копирование, удаление), **дефектные акты** (изменять, копировать, удалять, превращать в акт списания), печатные формы.
- **Справочник норм** — расход каждого материала на один стык/профиль; автоматический расчёт по количеству стыков объекта (из «Монтажа ГСВ»).
- **Объекты списания** — свои объекты со значениями по умолчанию (комиссия, кто утверждает); **Приказы** (журнал приказов); **Акты перевода материалов** (журнал переводов, остатки не меняет).
- Приход можно оформить из **накладной** (см. 3.15).

### 3.12. Калькуляторы
- **Плановая прибыль** (со своими настраиваемыми формулами расчёта),
- **Выделение НДС** (из суммы с НДС),
- **Конвертер величин** (длина, масса),
- **Объём земляных работ** (длина, глубина, ширина по дну и верху → объём грунта).

### 3.13. Статистика
Период (за всё время, сегодня, неделя, месяц, прошлый месяц, свой), фильтр оплат по разделам. Показатели: сумма смет, оплачено, материалы, работы, процент оплат от заключённых смет; график динамики выручки за 6 месяцев; сводки по договорам, оплатам и сметам.

### 3.14. Исполнительная документация и «Все реестры»
- **Исполнительная документация** — реестр по договорам: шаблоны Word/Excel, сертификаты, выборочное переформирование, печать сертификатов, история файлов, сверка.
- **Все реестры** — быстрый обзор всех реестров в одном месте и открытие записей двойным щелчком.

### 3.15. Входящие документы и накладные
- **Входящие документы:** перетащите накладную, сертификат или подписанный акт в любое место окна (или «Добавить файлы…»). Программа читает текст (PDF с текстом, Word, Excel; фото/сканы — через Tesseract), предлагает вид, номер, дату, сумму, контрагента и **объект для привязки**; вы проверяете, сохраняется только по кнопке. Файл копируется в папку объекта или во «Входящие». Для подписанного акта можно сразу отметить акт подписанным у объекта.
- **Накладные (Республика Беларусь):** вкладка «Накладные и товары».
  - Источники: Excel (электронные накладные, выгрузки), PDF с текстом, фото и сканы (Tesseract OCR, русский язык; поворот по EXIF, выравнивание, несколько режимов разбора).
  - Распознаётся: вид (ТН-2, ТТН, накладная), серия и номер, дата; поставщик и получатель (название, УНП, адрес, расчётный счёт IBAN, банк, БИК); таблица товаров (наименование, единица, количество, цена, стоимость, ставка НДС, сумма НДС, всего с НДС); итоги.
  - Окно проверки: арифметика каждой строки (количество × цена = стоимость; стоимость + НДС = всего), красная подсветка расхождений, автоисправление одиночных ошибок распознавания (жёлтым), сверка итога с документом, зелёная подсветка позиций, найденных в справочнике, кнопка подстановки названий из справочника, пересчёт при правке.
  - После сохранения: добавить поставщика в справочник юрлиц (по УНП), обновить закупочные цены и добавить новые позиции в справочник материалов (с наценкой), оприходовать на склад (один раз), сохранить файл. Экспорт накладной в Excel, поиск по номеру, поставщику, УНП и названию товара. Повторная загрузка той же накладной не сохраняется.

### 3.16. Сотрудники и бригады
- Сотрудники (монтажники, мастера, сварщики) с ролью и телефоном; «Подтянуть сварщиков» создаёт карточки из модуля «Сварщики».
- **Допуски и сроки:** удостоверения, аттестаты, медосмотры — просроченные и истекающие подсвечены, срок попадает в календарь.
- **Бригады;** **назначения** (кто на каком объекте и в какие даты) с предупреждением о пересечении и просроченном допуске; **график** занятости по дням месяца; загрузка бригад; предупреждения, если к началу работ не готовы материалы или документы.

### 3.17. Журнал и корзина
Все создания, изменения и удаления в основных реестрах, с указанием **кто** менял (в сети). «Что изменилось…» — было/стало. **Корзина:** фильтр «Только удалённые» → «Восстановить» возвращает запись и вложенные записи (оборудование, стыки и т. п.). Журнал хранится 400 дней.

### 3.18. Журнал ошибок
Необработанные сбои, сбои копирования, выгрузок и фоновых операций, окна «не сохранено». Для каждой: раздел, время, число повторов, подробности. «Копировать отчёт»/«Сохранить отчёт…» — текст для разработчика (версия, система, ошибки; данных базы нет). Счётчик новых ошибок в заголовке окна. Хранится 90 дней.

### 3.19. Справочники
- **Справочники ГСВ:** материалы, трубопроводы, сертификаты, правила подбора сертификатов (зависимые и по умолчанию).
- **Справочник ГСН:** отдельный, со своими позициями и сертификатами.
- **Справочник (общий) — материалы и работы:** дерево разделов с перетаскиванием, карточка позиции (название, тип, единица, цена, закупочная цена, примечание, ссылка), состав стоимости работ, импорт из Excel, удаление дубликатов, парсинг цен с сайта, **«Обновить цены по ссылкам»** (цены читаются с сайтов поставщиков, применяются только подтверждённые вами).
- **Вкладка «Группы товаров»:** именованные наборы позиций с количествами по умолчанию (создать, переименовать, копировать, удалить; добавление выбранных позиций из справочника или правым щелчком «Добавить в группу товаров…»; порядок; количество по умолчанию). В смете группа добавляется одной кнопкой.

### 3.20. Настройки
Внешний вид (название программы, видимость и названия вкладок, тема, шрифт, акцент); сетевая работа; **резервные копии и восстановление**; **копия вне компьютера**; **распознавание накладных по фотографии** (путь к Tesseract, проверка); **номера разделов договоров**; шаблоны экспорта (PDF, Excel, Word); папки договоров (где создавать новые папки по разделам); пароль входа; проверка целостности базы; Excel-выгрузки реестров (раз в час); проверка обновлений.

## 4. Сквозные механизмы

### 4.1. Документы по шаблонам
Шаблоны Word/Excel с тегами `{ТЕГ}` / `{{ТЕГ}}`: в договорах, актах, справках, исполнительной документации. Для каждого раздела свой набор тегов (редактор тегов, «Теги для шаблонов» — список всех тегов). Форматирование шаблона сохраняется (шрифты, выравнивание, таблицы, колонтитулы). Реквизиты организации и банка, суммы (в том числе прописью) и НДС подставляются из данных договора. Пользовательские шаблоны подключаются самостоятельно.

### 4.2. Нумерация договоров
Номер `NN-РР/ГГ` (порядковый номер в году, номер раздела, год). Для каждого вида договора свой номер раздела — настраивается вручную (7.3). Возможны ручная смена, обмен между карточками, резерв номеров.

### 4.3. Оплаты и акты
Оплаты по договорам, сметам, чекам и клиентам без договора; остаток; связь договора со сметой (общий учёт); опциональный ранее учтённый остаток. **Ведомость подписанных актов** за месяц по каждому разделу с датой оплаты и экспортом в Excel/PDF. Отметка «Акт подписан» влияет на статус «сдано».

### 4.4. Печать и PDF
Карточки договоров и реестры печатаются и сохраняются в PDF одной кнопкой; сметы, ведомости, карточка клиента, накладные (Excel).

### 4.5. Импорт и экспорт Excel
Импорт проектов ГСВ, договоров монтажа ГСВ/ГСН, материалов и норм, накладных. Выгрузки реестров в Excel; автоматическая выгрузка реестров договоров и карточек проектов раз в час в папку `excel_reports`.

### 4.6. Папки и файлы
Для договоров можно создать/привязать папку на диске (в указанном вами месте по разделам); вложения, файлы клиента, подпись «открыть папку». Входящие документы раскладываются по папкам объектов.

### 4.7. Блокировка карточек
Когда карточку (договор, смета, досье, сотрудник, позицию справочника) открыл один человек, второй видит «Карточку сейчас правит Иванов (ПК-3) с 10:15» и может открыть её **только для просмотра**. Отметка обновляется каждые 25 секунд, устаревшая снимается через 90 секунд. Работает и между сетевыми клиентами, и для программы на компьютере-сервере.

## 5. Резервные копии и защита данных

1. **Автоматические копии:** раз в час при запущенной программе (и при закрытии, если последней больше 30 минут): обе базы и папки `projects`, `templates`, `attachments`, `certificates_storage`; хранятся последние 24 (`backups/auto_*.zip`).
2. **Страховочные снимки** перед импортом, удалением клиента и обновлением версии (`backups/before_<причина>_*`).
3. **Копия вне компьютера** (второй диск или облачная папка): шифрованная (AES-GCM, пароль не короче 10 символов), по расписанию (24 часа по умолчанию), хранится 12 копий, **раз в 30 дней автоматическая проверка восстановлением**. Пароль копии хранится в защищённом виде средствами компьютера; запишите его отдельно.
4. **Проверка целостности:** вручную («Настройки») и раз в неделю автоматически на сервере/локальной программе (файлы SQLite и логические связи).
5. **Восстановление из копии** — в «Настройках» (в сети — только на сервере).
6. Все данные и копии не покидают ваши компьютеры, кроме папки внешней копии, которую выбираете вы.

## 6. Сетевая работа (4.1–4.3)

**Схема:** один компьютер офиса — **ПТО Сервер** (владеет базой), остальные запускают обычную программу в режиме клиента.

- **Защита:** шифрованный канал (HTTPS), проверка сертификата по отпечатку при первом подключении, пароли пользователей хранятся как PBKDF2-SHA256, ограничение числа попыток входа, клиентам запрещены команды изменения структуры базы.
- **Роли:** *Администратор* (всё, включая пользователей и журнал входов), *Руководитель* (все разделы и данные, видит «Кто в сети», снимает зависшие блокировки), *Сотрудник* (работа с данными; разделы можно скрыть), *Только просмотр*.
- **Права по разделам:** администратор снимает галочки с разделов, которые нужно скрыть от сотрудника; налоги/оплаты ИП и ввод оплат закрываются и на уровне базы, остальное — в интерфейсе.
- **Запомнить вход:** вместо пароля клиент хранит отзываемый ключ (180 дней), вход автоматический; отзывается сменой пароля, отключением пользователя или кнопкой «Забыть сохранённый вход».
- **Кто в сети и что открыто:** список подключённых, открытые карточки, снятие зависшей блокировки.
- **Журнал входов и действий администратора:** входы, выходы, неудачные попытки, блокировки, создание/изменение/удаление пользователей, смена паролей, снятие блокировок.
- **Автообновление списков:** открытый раздел сам перечитывается, когда данные изменил другой пользователь.
- **Обрыв связи:** окно «Нет связи с сервером» с автоповтором; прерванное действие продолжается, когда сервер вернулся; клиент входит заново незаметно.
- **Локальный режим рядом с сервером:** на компьютере-сервере можно работать и обычной программой (правки подписываются «имя (локально)»).
- **Окно сервера:** адреса для подключения, отпечаток сертификата, подключённые, открытые карточки, пользователи, журнал входов, состояние копий и проверки целостности, «Копия сейчас». Автозапуск (скрипты для Планировщика заданий, правило брандмауэра).
- Подробности: `docs/NETWORK_GUIDE_RU.md`.

## 7. Администрирование

### 7.1. Установка
Python 3.11/3.12: `start_windows.bat` или `pip install -r requirements.txt` и `python run.py`. Сборка в `dist\ПТО\` (PyInstaller, два exe: `PTO.exe` и `PTO_Server.exe`) и установщик Inno Setup (`packaging/installer.iss`). Для фото накладных — отдельная установка Tesseract OCR (русский язык).

### 7.2. Обновление версий
Программа сама делает страховочный снимок перед обновлением структуры базы; миграции идемпотентны (повторный запуск безопасен). В сети версии клиента и сервера должны совпадать по первым двум числам. Проверка обновлений — по желанию (задайте адрес).

### 7.3. Номера разделов договоров
«Настройки → Номера разделов договоров»: для каждого вида договора (монтаж ГСВ, проект ГСВ, прочие юрлиц, СМР юрлиц, ТО юрлиц, СМР физлиц) свой номер раздела (1–4 знака), вводится вручную; у разных видов не должен совпадать; меняет только новые договоры. `docs/SECTION_CODES_GUIDE_RU.md`.

## 8. Что проверено, а что нет

- Автотесты: около 280 (логика, интерфейс без экрана, весь набор повторно через настоящий ПТО Сервер). 10 GUI-сценариев проверяют основные разделы.
- **Не проверялось на реальной сети из нескольких компьютеров и в сборке для Windows** (в разработке был Linux). Распознавание накладных проверено на сгенерированных образцах, а не на ваших бланках и снимках с телефона.
- Известные ограничения: нет блокировки для мелких диалогов ввода; резервные копии и восстановление только на компьютере-сервере; файлы договоров и шаблоны в сети нужно держать в общей папке с одинаковым путём; загрузка фото с телефона напрямую на сервер не реализована; рукописные и сильно наклонённые накладные распознаются плохо.
