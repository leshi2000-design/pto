# ПТО 4.9.4 — исправлена ошибка «wrapped C/C++ object of type OptionalDate has been deleted»

**Причина.** Если в поле даты вводилось неверное значение (например, 99.99.9999), поле на 0,9 секунды подсвечивалось красным, а таймер, снимающий подсветку, обращался к полю по прошествии времени. Если за это время окно с полем закрывали, таймер срабатывал на уже удалённом поле — отсюда сообщение в `smetagaz\date_widgets.py`.

**Исправление.** Таймер подсветки теперь принадлежит самому полю и уничтожается вместе с ним; отложенное выделение текста при входе в поле тоже защищено. Аналогичный отложенный вызов найден и исправлен в кнопке «Копировать» (шаблоны, `gsv_view.py`). Добавлен автотест: закрытие окна до срабатывания таймера не вызывает ошибок.

Дата при этом не терялась: ошибка касалась только снятия красной подсветки.
