# СМЕТА-ГАЗ 2.4 — интерфейс, шаблоны, исполнительная документация и оплаты

Обновление учитывает файл «Правки по программе.txt», пункты 1–6. Пункт 7 в исходном файле пустой.

## Что изменилось

Общее оформление программы обновлено: боковое меню со значками, заголовки разделов, светлая и тёмная темы, единые таблицы, поля и кнопки. В реестре смет действия и фильтры разделены на две строки. Навигация между страницами остаётся компактной. Загрузка реестров остаётся постраничной; отчёты выгружают все подходящие записи, включая следующие страницы.

Перечень актов **ГСН больше не используется в ГСВ**. Настроенные в версии 2.3 ошибочные позиции ГСВ сохранены в архиве настроек базы; их исходные файлы не удаляются. В новом перечне ГСВ нет предустановленных актов. Их можно добавить после уточнения вашего состава документации.

## Исполнительная документация — отдельный раздел

Откройте **Исполнительная документация → Объекты и комплекты ИД → Создать документацию**.

1. Выберите ГСН либо ГСВ; для ГСВ уточните монтаж или проектирование.
2. Выберите существующий договор, создайте новый договор либо введите произвольное название объекта без договора. В поиске существующих договоров доступны первые 200 совпадений — уточните номер или название.
3. Сохраните новую карточку договора. В ней задаются клиент, технические сведения, материалы, оборудование и папка объекта.
4. В комплект подтянутся настроенные документы раздела и сертификаты выбранных материалов, трубопроводов и оборудования. Отметьте нужные документы. Привязанные в карточке документы сварочного модуля тоже копируются при формировании.
5. Дополнительные сертификаты добавьте кнопкой **Добавить сертификат**. Они относятся к этому комплекту и не меняют спецификацию договора. Один и тот же сертификат, полученный из нескольких источников, не дублируется.
6. Нажмите **Сформировать / переформировать ИД**. В папке объекта создаётся отдельная подпапка `ИД_ГСН_номер` либо `ИД_ГСВ_номер`.

В окне комплекта доступны документы, сертификаты, содержимое папки и история файлов. В карточке договора есть **Перечень ИД и папка** с переходом к комплекту. При открытии карточки непосредственно из главного окна кнопка переключает главный раздел на исполнительную документацию; во вложенных карточках открывается то же окно комплекта.

Чтобы изменить исходные сведения, откройте карточку договора, сохраните исправления и переформируйте комплект. Программа сравнивает содержимое шаблона, используемые теги и файлы сертификатов. Неизменившиеся документы не перезаписываются; отсутствующий результат создаётся повторно. Если изменившийся документ редактировался вручную, программа предложит сначала сохранить его отдельно и убрать из рабочей папки. Удалённые из выбора документы остаются на диске и в истории, чтобы не потерять сделанную работу.

Перенос уже сформированного комплекта в другую папку не выполняется автоматически: создайте новый комплект для другой папки. Восстановление резервной копии сохраняет связи папки с её файлами. История документов, созданных в 2.3, переносится в новый реестр; старые файлы открываются на вкладке **История файлов**.

Произвольный объект даёт тег названия объекта и вручную добавленные сертификаты. Если шаблону нужны паспорт, номер договора и другие сведения карточки, создайте договор: программа не выдумывает эти значения.

### Сертификаты и оборудование

В разделе ИД находятся общий **Справочник сертификатов**, **Материалы и сертификаты**, а также **Шаблоны ГСН / ГСВ**. Папки сертификатов создаются и переименовываются через контекстное меню дерева папок; категории материалов — в справочнике материалов.

В карточке материала можно выбрать сертификат по умолчанию. В конкретном договоре связь разрешается заменить. В строке оборудования указываются вид, модель и номер; кнопка **Привязать файл сертификата / паспорта** связывает с выбранным оборудованием локальный файл. Это доступно и для ГСН. Файл в справочнике хранится по пути; копия появляется при формировании комплекта и в резервном архиве.

**Печатать сертификаты** отправляет файлы системным приложениям Windows после подтверждения количества. Нужны установленный принтер и поддержка команды печати программой для соответствующего типа файла. Фактическая печать на принтере здесь не проверена. На других ОС открывайте сертификаты и печатайте из просмотрщика.

### Шаблоны ИД

Во вкладке **Шаблоны ГСН / ГСВ** выберите раздел, подключите Word/Excel к нужному виду документа либо добавьте собственный вид. Списки полностью раздельные. В окне комплекта кнопка **Теги и значения** показывает сведения его договора; двойной щелчок копирует тег. Основные теги ГСН перечислены в `GSN_TEMPLATES_GUIDE_RU.md`.

Не редактируйте шаблоны или исходные сертификаты другими программами во время генерации и резервирования.

## Универсальные шаблоны Word и Excel

Для смет, договоров, карточек клиентов, остатков, статистики, отчётов по оплатам, актов списания и дефектных актов используется окно **Документ по шаблону**.

- В смете — кнопка **Документ по шаблону**.
- В карточках договоров — **Договор по шаблону** или основная кнопка экспорта.
- Для клиента — **Клиенты → выбрать запись → Экспорт**.
- Для склада — **Списание → Остатки → Отчёт по шаблону**. Выгружаются все записи с текущими поиском, категорией и дополнительными фильтрами, а не только открытая страница.
- Для статистики — **Отчёт по шаблону** за выбранный период. Это сводка по всем сметам периода; локальный поиск в таблице популярных материалов её состав не ограничивает.
- Для денежных поступлений — выберите раздел и **Отчёт по оплатам за выбранный период**.

Нажмите **Подключить шаблон**, выберите `.docx` или `.xlsx`, задайте понятное имя. Можно хранить несколько шаблонов одного вида. Последний выбор запоминается отдельно для документа. Полный список тегов с текущими значениями показан в окне экспорта; есть поиск и копирование двойным щелчком. **Заменить файл** меняет выбранный общий шаблон данного вида — для отдельного макета создайте ещё один шаблон.

Старые `.doc`/`.xls` сначала сохраните в современных форматах. Исходный шаблон не изменяется. Готовый файл сохраняется отдельно. Неизвестный тег блокирует формирование. Пустые необязательные сведения универсальных отчётов печатаются знаком «—». В ИД используется строгая проверка обязательных тегов карточки.

### Смета: любое количество строк и подпись

В Word создайте таблицу: строка заголовков и одна образцовая строка с тегами. В Excel задайте заголовки колонок и строку тегов под ними, например:

| № | Наименование | Тип | Единица | Количество | Цена | Сумма |
|---|---|---|---|---|---|---|
| `{{items.index}}` | `{{items.name}}` | `{{items.item_type}}` | `{{items.unit}}` | `{{items.quantity}}` | `{{items.price}}` | `{{items.amount}}` |

Образцовая строка повторится для каждой позиции. Заранее создавать сотни пустых строк не нужно. Строки ниже, включая итоги, сдвинутся вниз. Оформление образцовой строки сохраняется. Разделы, материалы и работы выгружаются в порядке сметы.

Ниже таблицы разместите итоговые теги:

| Тег | Значение |
|---|---|
| `{{title}}` / `{{date}}` | Название и дата сметы |
| `{{client_name}}` / `{{client_phone}}` / `{{client_address}}` | Клиент |
| `{{materials_total}}` | Материалы с корректировкой |
| `{{works_total}}` | Работы с корректировкой |
| `{{social_total}}` | Социальные начисления |
| `{{overhead_total}}` | ОХР и ОПР |
| `{{profit_total}}` | Плановая прибыль |
| `{{subtotal}}` | Сумма до НДС с общей корректировкой |
| `{{vat_total}}` | НДС |
| `{{total}}` | Сохранённый итог сметы |
| `{{calculated_total}}` | Итог, рассчитанный по текущим позициям и настройкам |
| `{{paid}}` / `{{debt}}` | Учтённая оплата / остаток |
| `{{prepared_by}}` | Кто составил смету |
| `{{company}}` / `{{report_date}}` | Организация / дата формирования |

Перед экспортом укажите составителя в соответствующем поле. Значение по умолчанию задаётся в **Настройки → Настройки экспорта → Смету составил**. Строку `Составил: {{prepared_by}} Подпись: __________` разместите после итогов. Если тега составителя в шаблоне нет, программа сама добавит строку подписи в конец документа; в Excel — внизу первого листа. При этом фиксированная область печати первого листа снимается, чтобы подпись не оказалась за её пределами. Для полного контроля печати используйте собственную строку с тегом.

### Другие повторяющиеся таблицы

| Документ | Теги строки |
|---|---|
| Остатки | `{{items.name}}`, `{{items.category}}`, `{{items.unit}}`, `{{items.balance}}`, `{{items.notes}}` |
| Оплаты | `{{payments.date}}`, `{{payments.amount}}`, `{{payments.section}}`, `{{payments.number}}`, `{{payments.object_name}}`, `{{payments.client_name}}`, `{{payments.note}}` |
| Сметы статистического отчёта | `{{estimates.title}}`, `{{estimates.date}}`, `{{estimates.client_name}}`, `{{estimates.total}}`, `{{estimates.paid}}` |
| Статистика по месяцам | `{{months.month}}`, `{{months.total}}`, `{{months.paid}}` |
| Позиции статистики | `{{items.name}}`, `{{items.item_type}}`, `{{items.unit}}`, `{{items.quantity}}`, `{{items.amount}}` |
| Договоры клиента | `{{contracts.number}}`, `{{contracts.date}}`, `{{contracts.object_name}}`, `{{contracts.amount}}` |
| Материалы ИД | `{{materials.name}}`, `{{materials.unit}}`, `{{materials.quantity}}`, `{{materials.certificate_number}}` |
| Оборудование ИД | `{{equipment.name}}`, `{{equipment.kind}}`, `{{equipment.model}}`, `{{equipment.certificate_number}}` |

В отчёте по оплатам итоги: `{{payment_total}}`, `{{payment_count}}`, `{{period_start}}`, `{{period_end}}`, `{{section}}`. В карточке клиента доступны `{{name}}`, `{{phone}}`, `{{address}}`, `{{passport}}`, `{{passport_issuer}}`, `{{passport_date}}`, `{{notes}}`. Для договоров доступны основные теги ГСН/ГСВ и поля самой записи. Для актов списания и дефектных актов таблицы обозначаются `section_1`, `section_2` и т. д.; колонки — `c1`, `c2`, …; их значения и состав показаны в окне тегов.

### Ограничения макетов

Одна повторяющаяся строка должна относиться к одной таблице данных. Повторение целых разделов и вложенных таблиц Word не реализовано. В Excel-шаблоне с повторяющимися строками используйте **готовые итоговые теги вместо формул**: программа отклонит такой шаблон, если в книге есть формулы, чтобы не исказить расчёт после вставки строк. В повторяемом листе не поддерживаются диаграммы, структурированные таблицы Excel и именованные диапазоны книги; обычные ячейки, стили, объединение по горизонтали и область печати поддерживаются. Объединение по вертикали не должно пересекать образцовую строку.

Шаблоны без повторяющихся строк сохраняют существующие формулы; пересчёт выполняется Excel. Числовые теги целой ячейки записываются числами. Для Word тег должен находиться в одном абзаце; различное оформление его частей допускается.

Стандартный экспорт Word/Excel/PDF оставлен дополнительной кнопкой. Пользовательские макеты генерируются в формате исходного шаблона — DOCX или XLSX; PDF из них сохраняйте в Word/Excel. Реальные бланки пользователя пока не предоставлены и не настроены.

## Оплаты по договорам и сметам

Кнопки **Оплаты** есть в карточках и реестрах ГСН, договоров ГСВ и проектирования ГСВ. Смета для приёма оплаты не обязательна. В договоре ГСН появилась сумма договора.

Если договор связан со сметой, история общая: платёж записывается один раз, виден в обоих документах и один раз попадает в отчёт. В окне оплат можно связать договор с существующей сметой; прежние самостоятельные платежи договора объединятся с историей сметы. Смета, не связанная с договором, продолжает вести свой учёт.

Смета связывается с одним договором. Перепривязка договора, у связанной сметы которого уже есть платежи, блокируется, чтобы не переносить деньги между объектами. Итог сметы и сумма договора могут различаться; каждый документ показывает остаток относительно своей суммы. Для ошибочного платежа предусмотрено удаление с подтверждением.

При обновлении положительная разница между старым полем «Оплачено» и суммой известных платежей сохраняется как начальная учтённая оплата. Она показывается отдельно и не выдаётся за новый платёж выбранного периода. Отчёт по оплатам строится по **датам платежей**, даже если договор или смета оформлены раньше периода. Разделы: ГСН, ГСВ, проектирование ГСВ, сметы без договора. Оплаты видны и в общем календаре.

## Задачи

Задачи представлены постраничной таблицей с поиском, выбором статуса, тега и архива. Теги выбираются в карточке задачи; допускается несколько тегов. Справочник **Теги и статусы** позволяет добавлять и переименовывать значения, искать их. Используемые значения нельзя удалить до снятия связей; базовые статусы можно переименовать. Общий поиск также находит задачи по тегам и названиям статусов. Календарь остаётся отдельной вкладкой.

## Обновление и проверки

Распакуйте всю сборку, не заменяйте только отдельные `.py` файлы: появились новые модули. В Windows запускайте `start_windows.bat`; инструкция Python — в README. Рабочие базы хранятся отдельно от исходников. Перед миграцией сохраняется снимок баз.

Новые таблицы, выбранные шаблоны, папки комплектов и их история включены в резервирование. Не храните резервный архив внутри папки документов объекта. Доступные внешние сертификаты копируются в резервный архив; недоступные перечисляются в отчёте копирования. Для документов сварочного модуля по-прежнему сохраняются исходные ссылки; копии, включённые в сформированную ИД, резервируются вместе с папкой комплекта.

Проверены автоматические тесты, сценарии интерфейса Qt в Linux, обновление с выданной версии 2.3, сохранение истории, общие оплаты, повторное формирование ИД и восстановление путей. Windows, системная печать и реальные пользовательские бланки требуют проверки на рабочем компьютере.
