# Веб-доступ к ПТО — прототип (4.10.0)

## Как это устроено
Это **не отдельная программа и не копия базы**: в ПТО на компьютере с базой появляется встроенный веб-сервер (отдельный поток). Другие компьютеры, планшеты и телефоны открывают в обычном браузере адрес вида `https://192.168.0.15:8765` — ничего устанавливать на них не нужно. Все они работают с той же базой, что и окно программы; блокировка карточек (`gsvm:<id>`) защищает от одновременной правки: если карточка открыта в программе, веб-правка отклоняется, и наоборот.

В прототипе — **«Монтаж ГСВ»**: список с поиском, карточка договора (клиент, несколько телефонов, паспорт, объект, подписи, оборудование: котёл/колонка/…, модель и серийный номер) и блок «Данные клиента для копирования» с кнопкой копирования в буфер обмена (на телефоне — прямо из браузера). Телефоны в списке — ссылки (`tel:`): нажатие — звонок.

## Как включить
1. **Настройки → «Веб-доступ (прототип)»**.
2. **«Пользователи…» → «Добавить…»**: логин, пароль (не короче 8 символов), права — «Только просмотр» или «Сотрудник (может править)».
3. Отметьте «Включить веб-доступ» (HTTPS оставьте включённым, порт 8765 можно изменить) → **«Применить»**. Ниже появится адрес(а) для браузера.
4. В **брандмауэре Windows** разрешите доступ для **частной сети** (Windows спросит при первом запуске).
5. На другом устройстве (в той же сети Wi‑Fi/LAN) откройте адрес. Браузер предупредит о **самоподписанном сертификате** — это ожидаемо (соединение шифруется, но сертификат выдан не публичным центром): «Дополнительно → Перейти на сайт». Затем войдите логином и паролем.

Включённый веб-доступ запоминается и запускается вместе с программой. Работает, **пока программа открыта** на этом компьютере.

## Безопасность (что сделано)
* Только локальная сеть, интернет не используется; наружу из сети сервер не «пробрасывается» — не открывайте порт на роутере.
* HTTPS (TLS ≥ 1.2); cookie сессии `HttpOnly`, `SameSite=Strict`, `Secure`; сессия закрывается через 8 часов простоя.
* Пароли в базе — только в виде PBKDF2-SHA256 (200 000 итераций) с солью; сравнение за постоянное время.
* Защита от подбора: 5 неудачных входов за 5 минут с одного адреса — блокировка на минуту.
* Правка защищена CSRF-токеном; роль «Только просмотр» не может сохранять; при правке проверяется блокировка карточки.
* Все данные экранируются в HTML; заголовки `Content-Security-Policy`, `X-Frame-Options: DENY`, `no-store`; размер запроса ограничен.
* Меняются только разрешённые поля: **номер договора, смета, суммы, папка, статусы, файлы веб-клиентом не меняются**; файл паспорта оборудования при правке сохраняется.

## Что НЕ сделано в прототипе (дорожная карта)
1. Остальные разделы: Проекты ГСВ, Монтаж ГСН, СМР/ТО/юрлица, клиенты, контакты, оплаты — по тому же шаблону (каждый раздел: список + карточка).
2. Создание новых договоров, вложения (фото, сканы с телефона: «сфотографировал паспорт оборудования — прикрепилось к карточке»), печать/формирование документов.
3. **Работа без включённого ПК-клиента:** перенос веб-сервера в «ПТО Сервер» (он круглосуточный владелец базы, со своими пользователями и ролями admin/manager/editor/viewer) — тогда веб-клиенты, настольные клиенты и телефоны работают с одним сервером, а вход идёт по тем же учётным записям.
4. Установка сертификата на устройства (чтобы не было предупреждения), QR-код с адресом, «добавить на главный экран» (PWA), журнал действий веб-пользователей в «Журнале и корзине».
5. Права по разделам для веб-пользователей (как у сетевых).

## Варианты архитектуры (для выбора дальше)
| Вариант | Плюсы | Минусы |
|---|---|---|
| **Встроенный веб-сервер в ПТО (прототип)** | ничего не нужно ставить; одна база; быстро | доступ, только пока ПТО открыта на этом ПК |
| **Веб-сервер в «ПТО Сервер»** (рекомендуется для постоянной работы) | круглосуточно; единые пользователи и права; настольные клиенты и веб — к одному серверу | нужен компьютер, где сервер всегда включён |
| Облако / доступ из интернета | работа из любого места | риски безопасности и хранения персональных данных (паспорта); не рекомендуется без отдельной защиты (VPN) |
| Родное мобильное приложение | удобнее камера, офлайн | отдельная разработка под iOS/Android; для основных функций веб достаточен |

Для выезда к клиенту без Wi‑Fi объекта: VPN до домашней сети (например, встроенный в роутер) — тогда тот же адрес работает и с мобильного интернета; открывать порт напрямую в интернет не нужно.
