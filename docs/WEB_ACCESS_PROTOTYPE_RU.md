# Веб-доступ к ПТО (4.11.0)

## Как это устроено
Это **не отдельная программа и не копия базы**: в ПТО на компьютере с базой работает встроенный веб-сервер. Другие компьютеры, планшеты и телефоны открывают в обычном браузере адрес вида `https://192.168.0.15:8765` — ничего устанавливать не нужно. Все работают с той же базой, что и окно программы; изменения из браузера записываются в базу сразу и видны в программе после переключения вкладки/обновления списка (открытая в программе карточка «на лету» не обновляется — для этого есть блокировка карточек: если карточка открыта в программе, веб-правка отклоняется, и наоборот).

## Что есть в веб-версии
Внешний вид повторяет программу: **те же цвета, боковое меню с теми же значками и разделами**, светлая/тёмная тема и акцентный цвет берутся из «Настроек» программы. На телефоне меню сворачивается в кнопку «☰ Меню», таблицы превращаются в карточки.

| Раздел | Модули | Что можно |
|---|---|---|
| **Услуги** | Проекты ГСВ, Монтаж ГСВ, Монтаж ГСН, СМР (ИП), СМР (физлица) | список с поиском, карточка: клиент/контрагент, телефоны, паспорт, объект, даты, суммы, подписи; оборудование (ГСВ), акты (СМР); кнопка «Скопировать данные клиента» (Монтаж ГСВ). Создание — Монтаж ГСВ, СМР (ИП), СМР (физлица) |
| **Клиенты** | Клиенты, Контакты | поиск, правка и создание |
| **Юрлица** | Справочник юрлиц, СМР (юрлица), ТО (юрлица), Прочие (юр.лица) | поиск, правка и создание; контактные лица юрлица; договоры с актами, ставкой НДС, статусом и «визуальным статусом вручную» |

Не делается в браузере (остаётся в программе): создание **Проектов ГСВ** и **договоров Монтаж ГСН** (номера присваиваются в программе), сметы, формирование документов Word/Excel, файлы и папки, оплаты, перенос договоров, шаблоны, настройки. Номера новых договоров назначаются так же, как в программе.

## Как включить
1. **Настройки → «Веб-доступ»**.
2. **«Пользователи…» → «Добавить…»**: логин, пароль (не короче 8 символов), права — «Только просмотр» или «Сотрудник (может править)».
3. Отметьте «Включить веб-доступ» (HTTPS оставьте включённым) → **«Применить»**. Ниже появятся адрес сайта и **«Страница сертификата»**.
4. Нажмите **«Разрешить в брандмауэре»** (Windows спросит подтверждение администратора). Будет создано правило «PTO Web»: вход по TCP на порт веб-доступа и порт+1, только из вашей подсети, для любых типов сети (частная/общедоступная).
5. Нажмите **«Проверить доступ»** — программа покажет, что с сетью, адресами и брандмауэром.

## Почему браузер писал «подключение не защищено» и как это убрать
Раньше сертификат был самоподписанным — браузер не знал, кто его выдал. Теперь программа создаёт **собственный центр сертификации «ПТО»** и им подписывает сертификат сайта (он действителен для IP-адреса и имени компьютера; при смене адреса перевыпускается сам). Предупреждение исчезает **после того, как центр ПТО один раз установлен на устройстве** (без этого невозможно: браузеры доверяют только центрам, которые установлены в системе; публичный сертификат на локальный IP получить нельзя).

На устройстве откройте **«Страницу сертификата»** (адрес `http://<IP компьютера>:<порт+1>`, он показан в настройках) — там инструкция и кнопка скачивания:
* **Android**: скачать → Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → *Сертификат ЦС*.
* **iPhone/iPad**: скачать профиль → Настройки → «Профиль загружен» → Установить; затем Настройки → Основные → Об этом устройстве → Доверие сертификатов → включить «ПТО — центр сертификации».
* **Windows**: открыть файл → Установить сертификат → Локальный компьютер → «Доверенные корневые центры сертификации».
* Сверьте отпечаток SHA-256 на странице с тем, что показывает программа («Сохранить сертификат ПТО…»).

Страница сертификата работает по обычному http (на ней нет данных ПТО, только публичный сертификат). Закрытый ключ центра хранится только на компьютере с программой (`web_cert/` в папке данных) — не копируйте и не отправляйте эту папку.

## Если телефон не заходит на сайт
Самые частые причины (порядок — по частоте):
1. **Брандмауэр Windows** — нет разрешающего правила. Кнопка «Разрешить в брандмауэре».
2. **Телефон не в той же сети**: должны совпадать первые три числа адреса (например, `192.168.0.x`). «Гостевая» сеть Wi‑Fi и функция роутера «изоляция клиентов/AP isolation» запрещают устройствам видеть друг друга.
3. **Мобильный интернет/VPN/частный DNS на телефоне** — запрос уходит не в вашу сеть; отключите на время.
4. Несколько сетевых адресов у компьютера (Wi‑Fi + кабель + виртуальные адаптеры) — открывайте тот адрес, что из вашей сети; программа показывает все.
5. Порт занят другой программой — выберите другой порт.
6. Если HTTPS у конкретного телефона не получается, можно временно отключить HTTPS (будет «не защищено», но работать), пока не установлен сертификат.

## Безопасность (что сделано)
* Только локальная сеть, интернет не используется; не пробрасывайте порт на роутере.
* HTTPS (TLS ≥ 1.2); cookie сессии `HttpOnly`, `SameSite=Strict`, `Secure`; сессия закрывается через 8 часов простоя.
* Пароли — только PBKDF2-SHA256 (200 000 итераций) с солью; защита от подбора: 5 неудачных входов за 5 минут — блокировка на минуту.
* Правка защищена CSRF-токеном; роль «Только просмотр» не может сохранять; проверяется блокировка карточки программы.
* Данные экранируются в HTML; `Content-Security-Policy`, `X-Frame-Options: DENY`, `no-store`; размер запроса ограничен.
