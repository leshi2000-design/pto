# Версия 3.7: даты, статусы Монтаж ГСВ, объекты списания, цены по ссылкам

## Даты
- Формат везде **дд.мм.гггг** (таблицы, поля, Excel-выгрузки). Календарь на русском, неделя с понедельника, цифры и дни недели читаются.
- Дату можно **вводить цифрами** (например, `14102026`) или выбирать в календаре. Календарь пустого поля открывается на сегодняшнем месяце, а не на 1900 годе; в «Дата выполнения» по умолчанию стоит сегодня. Delete очищает необязательную дату.

## Сварщики
Таблица сварщиков показывает все данные, включая примечания; ширина колонок подстраивается под содержимое (её можно менять вручную). Работают «Выборки» и «Колонки».

## Ведомость подписанных актов
Добавлена колонка **«Дата оплаты»** (дата последнего платежа по договору); она попадает и в Excel.

## Папки договоров
«Настройки → Папки договоров»: для каждого раздела (Проекты ГСВ, Монтаж ГСВ, Монтаж ГСН, Юрлица, СМР) можно указать свою корневую папку. Новые папки договоров создаются в ней без лишних вопросов; пока путь не задан, программа спрашивает место при создании.

## Закрытие программы
Окно закрывается сразу; нужная резервная копия (если последней больше 30 минут) делается в фоне.

## Монтаж ГСВ
- **Свои статусы** (кнопка «Статусы…» в реестре): статусы работы и клиента, свои цвета, порядок, несколько статусов на договоре. Они не связаны со статусами «Проектов ГСВ».
- **Главная таблица:** № договора, Дата заключения, Объект / Адрес, Клиент, Стоимость, Статусы, Примечание (без порядкового номера строки).
- **Передача исполнительной документации:** в карточке договора — галочка «ИД передано», кому (клиенту или напрямую в ГорГАЗ) и дата передачи.

## Списание
- **Дефектные акты:** изменение (пока по акту нет списания), **«Копия на основании»**, удаление.
- **Акты списания:** удаление в любом статусе (у проведённого материалы возвращаются на остаток).
- **Материалы:** удаление (вместе с поступлениями и строками норм); если материал уже есть в актах, его можно **скрыть**. Двойной щелчок по материалу открывает **все поступления и списания** с остатком после каждой операции.
- **Объекты списания:** свои объекты (например, собственное здание) и объекты, связанные с ГСВ/ГСН. В актах объект выбирается из списка.
- **Значения по умолчанию:** организация, кто утверждает, комиссия, основания, условия — подставляются в новые акты; у объекта можно задать свои значения.
- Удалённое можно вернуть через «Журнал и корзина».

## Цены по ссылкам (Справочник)
1. В карточке позиции укажите **ссылку** на страницу товара (и при необходимости **селектор цены**). Кнопка «Проверить цену по ссылке» покажет найденную цену.
2. «Справочник → **Обновить цены по ссылкам**» проверяет все позиции со ссылкой (или выделенные) в фоне, с прогрессом и отменой. Показывается таблица «было → стало → изменение»; применяются только отмеченные цены.
3. Резкое изменение цены (в 3 раза и более), ошибки сети и страницы без цены не применяются автоматически — они помечаются для проверки. История цен — в карточке позиции.
4. Селектор запоминается для сайта: у других товаров того же сайта он подставляется сам. Если селектор не задан, цена ищется в стандартной разметке (schema.org, Open Graph, JSON-LD).
- Ограничения: страницы, где цену подставляет скрипт, и сайты с входом простым запросом не читаются — для них используйте прайс-лист поставщика (Excel) и «Импорт Excel».
