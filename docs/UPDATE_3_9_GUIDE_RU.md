# ПТО 3.9 — модуль «Монтаж ГСН»

Модуль отдельный: с остальными разделами его связывают только **Клиенты** и **Сметы**. Заказчик — только физлицо.

## Карточка договора (4 вкладки)
1. **Договор и клиент** — адрес/объект, клиент (автоматически попадает в «Клиенты», есть выбор из списка и проверка по ФИО), примечания, проект (месяц и год), сроки и стоимость, смета, договор и справка об оплате.
   - Начало работ = дата заключения; окончание = +60 дней (можно изменить).
   - «Акт подписан» не отмечен — работа не сдана.
   - Смета: «Нет данных» → создать/привязать → «Получить стоимость из сметы» → при изменении сметы «обновите данные»; есть история изменений.
2. **Трубопроводы и оборудование** — ПЭ 32 и сталь 25 (метры), тип газопровода, врезка: в сталь → 1 неразъёмное соединение ПЭ/сталь + муфты; в ПЭ → 1 заглушка + муфты. Сертификаты и аттестаты сварщиков: «по умолчанию» и «зависимые».
3. **Исполнительная документация** — 12 документов (титульник, реестр ИД, гарантийный паспорт, акт приёмки, строительный паспорт, акт скрытых работ, акт ревизии устройств, 4 протокола ВКК, акт передачи материалов).
4. **Шаблоны и теги** — шаблон Word для каждого документа и редактор тегов; тегом снабжено каждое поле карточки.

## Справочник ГСН
- У позиции задаётся «Роль в договоре ГСН» (труба ПЭ/сталь, неразъёмное соединение, заглушка, муфта).
- Сертификат с отметкой «По умолчанию» подставляется во все объекты; остальные — через позиции.
- Вкладка «Аттестаты сварщиков»: правило для каждого аттестата (всем объектам / только врезка в сталь / в ПЭ).

Шаблоны по умолчанию — заготовки; свои шаблоны подключаются на вкладке «Шаблоны и теги». База данных обновляется автоматически, данные сохраняются.
