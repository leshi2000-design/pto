# ГСН и ГСВ: карточки и исполнительная документация, версия 2.3

В программу добавлен механизм заполнения **ваших существующих** Word/Excel-шаблонов. Официальные бланки не приложены: их не было среди предоставленных файлов. Программа не определяет места вставки по смыслу — в нужные места исходного шаблона один раз нужно вписать теги.

## Начало работы

1. Откройте **ГСН → Создать договор**. Введите номер, дату, название и адрес объекта. Введите клиента либо выберите существующего. После сохранения клиент появляется в общей базе клиентов.
2. Во вкладке **Исполнительная документация → Данные для документов** внесите проект, технические условия, сроки и количества. ФИО указывается в порядке «Фамилия Имя Отчество». Сокращения формируются автоматически; для сложных фамилий/инициалов можно уточнить оба варианта вручную.
3. Во вкладке **Материалы и сертификаты** выберите материал из справочника или введите произвольно. Выберите вид: заглушка, муфта, ввод, стальная труба, полиэтиленовая труба, переход либо прочий материал. Введите количество. Трубы — в метрах, остальные перечисленные изделия — в целых штуках. Итоги по видам складываются из строк; они имеют приоритет над ручными итогами. Если строк этого вида нет, используется ручной итог. Нулевое количество введите явно как `0`.
4. У материала из справочника автоматически выбирается его сертификат. Общую связь можно назначить в карточке материала. В договоре можно выбрать другой сертификат или привязать новый файл с номером — это не меняет сертификат справочника и других договоров. Файлы остаются на компьютере; сохраняются ссылки. Данные сертификата читаются из его актуальной карточки.
5. Во вкладке **Шаблоны и папка** привяжите существующую папку договора. Её содержимое отображается внутри программы; двойной щелчок открывает файл в установленном приложении. Папка должна быть доступна для записи. Для каждого объекта лучше использовать отдельную папку.
6. Выделите документ и нажмите **Настроить шаблон**. Укажите `.docx` или `.xlsx`, имя результата и область настройки: все договоры соответствующего модуля или только этот договор. Индивидуальная настройка имеет приоритет. Снятие «Только для этого договора» сохраняет общий шаблон и убирает индивидуальное исключение.
7. Откройте **Теги и значения**, скопируйте нужные теги в шаблон. Отметьте документы галочками и нажмите **Создать выбранные документы**. Данные карточки предварительно сохраняются. Генерация выполняется в фоне.

Для ГСВ тот же механизм находится во вкладке **Шаблоны ГСВ и материалы** карточек договоров на работы и проектов ГСВ. Сроки монтажного договора берутся из основной карточки. Шаблоны ГСН и ГСВ настраиваются отдельно. Сертификаты существующих трубопроводов ГСВ также попадают в общий список материалов/сертификатов. Вид трубы для отдельных итогов нужно указывать в новой таблице материалов, а не угадывать по названию.

## Подключаемые документы

- Титульник.
- Акт освидетельствования скрытых работ на сигнальную ленту.
- Акт приёмки в эксплуатацию.
- Акт ревизии технических устройств.
- Гарантийный паспорт.
- Договор.
- Протокол входного контроля трубы.
- Протокол входного контроля ввода.
- Протокол входного контроля муфты.
- Распечатка со сварочного аппарата.
- Реестр.
- Строительный паспорт.

Для настоящей распечатки аппарата используйте **Добавить готовый файл / распечатку аппарата**. Программа копирует выбранный файл в папку объекта; показания аппарата не генерирует. Соответствующий слот шаблона можно использовать для сопроводительного листа. Этой же кнопкой можно добавить другие готовые PDF, сканы и документы.

## Основные теги

Тег помещается в текст Word, ячейку Excel, таблицу или колонтитул. Скобки обязательны. Допустимы пробелы только вокруг имени: `{{ фио }}`. Один тег должен находиться внутри одного абзаца Word или одной ячейки Excel. Разное оформление частей тега в одном абзаце поддерживается.

| Тег | Значение / пример |
|---|---|
| `{{номер_договора}}` | Номер договора |
| `{{дата_договора}}` | 19 сентября 2026 г. |
| `{{дата_договора_кратко}}` | 19.09.26 |
| `{{contract_date_numeric}}` | 19.09.2026 |
| `{{фио}}` | Иванов Иван Иванович |
| `{{ио_фамилия}}` | И.И.Иванов |
| `{{фамилия_ио}}` | Иванов И.И. |
| `{{фамилия_ио_с_запятой}}` | Иванов, И.И. |
| `{{паспорт}}` | Номер, орган выдачи и дата, если заполнены |
| `{{passport}}` / `{{passport_issuer}}` / `{{passport_date}}` | Паспортные данные по отдельности |
| `{{телефон}}` | Телефон клиента |
| `{{адрес}}` | Адрес клиента |
| `{{object_address}}` | Адрес объекта |
| `{{объект}}` | Название объекта строительства |
| `{{проект}}` | Номер и дата проектной документации |
| `{{проект_номер}}` / `{{проект_дата}}` | Номер / дата отдельно |
| `{{начало_строительства}}` / `{{окончание_строительства}}` | Сроки строительства |
| `{{ту}}` | Номер и дата технических условий |
| `{{ту_номер}}` / `{{ту_дата}}` | Номер / дата отдельно |
| `{{количество_заглушек}}` | Заглушки, шт. |
| `{{количество_муфт}}` | Муфты, шт. |
| `{{количество_вводов}}` | Газопроводы-вводы, шт. |
| `{{труба_сталь_количество}}` | Стальная труба, м |
| `{{труба_пэ_количество}}` | Полиэтиленовая труба, м |
| `{{количество_переходов}}` | Переходы сталь–полиэтилен, шт. |
| `{{материалы}}` | Многострочный список материалов с количеством |
| `{{сертификаты}}` | Материалы и номера связанных сертификатов |
| `{{реестр}}` | Перечень документов текущего создаваемого комплекта с именами файлов |

Сроки и даты проекта/ТУ также доступны в короткой форме: `{{project_date_short}}`, `{{tu_date_short}}`, `{{start_date_short}}`, `{{end_date_short}}`. Суффикс `_iso` возвращает дату `2026-09-19`.

## Сертификаты конкретного вида материалов

| Вид | Префикс |
|---|---|
| Заглушки | `cap` |
| Муфты | `coupling` |
| Вводы | `inlet` |
| Стальная труба | `steel_pipe` |
| Полиэтиленовая труба | `pe_pipe` |
| Переходы сталь–полиэтилен | `transition` |
| Прочие материалы | `other` |

После префикса добавьте:

- `_name` — наименования, например `{{pe_pipe_name}}`;
- `_quantity` — итоговое количество, например `{{coupling_quantity}}` (для `other` итог отсутствует: единицы могут различаться);
- `_certificate_name` — название сертификата;
- `_certificate_number` — номер, например `{{pe_pipe_certificate_number}}`;
- `_certificate_valid_to` — срок действия из справочника сертификатов.

Если у вида несколько материалов или сертификатов, значения объединяются через точку с запятой. Для точного соответствия строки и сертификата используйте теги конкретной строки: `{{material_1_name}}`, `{{material_1_quantity}}`, `{{material_1_unit}}`, `{{material_1_certificate_number}}`, `{{material_1_certificate_name}}`, `{{material_1_certificate_valid_to}}`, `{{material_1_note}}`. Нумерация соответствует порядку материалов в карточке; существующие трубопроводы ГСВ идут после них. После изменения порядка проверьте шаблон. Строки таблиц автоматически не размножаются: предусмотрены индексированные теги и общие многострочные списки.

## Что происходит при создании

- Проверяется наличие всех выбранных шаблонов и значений используемых тегов. Пустой или неизвестный тег блокирует весь комплект; выводится причина. Неиспользуемые в шаблоне поля можно не заполнять. Старые `.doc`/`.xls` сначала сохраните в Word/Excel как `.docx`/`.xlsx`.
- Сохраняются структура OOXML, таблицы, оформление, изображения и формулы. Количество, занимающее целую ячейку Excel, записывается числом, чтобы его могли использовать формулы. Формулы Excel программа не пересчитывает — расчёт выполняет Excel/совместимое приложение. Если в исходном файле включён ручной расчёт, пересчитайте формулы в Excel (F9). Теги внутри самих формул не поддерживаются.
- Исходный шаблон остаётся неизменным. Каждый результат получает уникальный суффикс. Уже существующие документы не перезаписываются. Формирование нового комплекта не меняет ранее созданные документы при изменении клиента или сертификата.
- Отмеченная опция **Добавить файлы сертификатов** копирует доступные привязанные сертификаты рядом с документами. Отсутствующий файл связанного сертификата блокирует комплект с сообщением. Можно восстановить путь либо снять опцию копирования; данные сертификата всё равно используются в тегах.
- Журнал созданных документов сохраняет время, снимок использованных значений и SHA-256. В ГСВ созданные документы и сертификаты материалов также видны в общей исполнительной документации.
- В реестр вставляется состав текущего комплекта. Дополнительные готовые файлы видны в папке; они автоматически в текст реестра не включаются.
- Новые шаблоны и папки договоров включены в резервное копирование. Копию нельзя помещать внутрь резервируемой папки договора — программа сообщит об этом. После восстановления относительные пути новых шаблонов и папок работают из восстановленной папки данных.

Длина подставленного текста может менять разбиение на страницы. Перед использованием проверьте готовый документ в Word/Excel. Конвертация новых заполненных шаблонов в PDF в этом механизме не добавлена; сохраните PDF из Word/Excel. Общий экспорт приложения Word/Excel/PDF сохранён.

Проверка выполнена на синтетических DOCX/XLSX и в Linux без физического экрана. Для точной настройки ваших существующих бланков нужны сами исходные файлы; готовность их оформления без них не подтверждается.
