# ПТО 4.16.0 — ведомость актов в веб-клиенте и работа в фоне

## 1. Веб-клиент: «Ведомость актов» за месяц по всем разделам
Меню **«Оплаты и ведомости» → «Ведомость актов»** (доступна и роли «Только просмотр»):
* выбор месяца (стрелки «← предыдущий / следующий →» и поле месяца); по умолчанию — период, за который сдаётся ведомость (до 10-го числа — прошлый месяц);
* сводка по всем разделам: **Проекты ГСВ, Монтаж ГСВ, Монтаж ГСН, СМР (ИП), СМР (физлица), СМР (юрлица), ТО (юрлица), Прочие (юр.лица)** — подписанные и не подписанные акты, количество и суммы, общий итог;
* ниже по каждому разделу, где за месяц есть акты, — таблицы подписанных и неподписанных актов: дата, договор (ссылка на карточку), клиент, объект и адрес, сумма, оплачено, остаток;
* кнопка **«Скачать Excel»** — файл с листами «Подписанные акты» и «Не подписаны», с колонкой «Раздел», итогами по разделам и общим итогом.
Расчёт тот же, что в окне «Ведомость подписанных актов» программы.

## 2. Работа в фоне: веб-доступ доступен, пока включён компьютер
**Настройки → «Сеть и доступ» → «Работа в фоне»:**
* **«Закрытие окна сворачивает программу в значок у часов»** — крестик не завершает программу: веб-доступ, автоматические копии и напоминания продолжают работать. Первый раз программа подскажет об этом сообщением. Открыть — щелчок по значку; **полный выход** — правая кнопка по значку → «Выход». При выключении/выходе из Windows программа закрывается обычным образом (с копией базы).
* **«Запускать вместе с Windows (свёрнутой в значок, без окна)»** — запись в реестре текущего пользователя (без прав администратора, ключ `--background`). Если у программы задан пароль входа, он спрашивается при открытии окна из значка; веб-доступ работает и без него (у него свои пользователи).
* Повторный запуск ярлыка, пока программа работает в фоне, **открывает её окно**, а не пишет «папка данных уже открыта».
* Включённый автозапуск включает и режим «в фоне»; выключение режима снимает автозапуск.

Важно знать:
* Программа стартует **при входе в Windows** (не до входа в систему). Чтобы сайт был доступен после включения компьютера без ручного входа, включите в Windows автоматический вход для этой учётной записи.
* Если компьютер **уходит в сон**, сайт недоступен: в настройках электропитания Windows отключите сон («Никогда»).
* Если значка у часов нет (нестандартная оболочка), режим не включается — окно закрывается как обычно.
* Для круглосуточной работы без пользовательского сеанса (как служба) по-прежнему подходит «ПТО Сервер»; веб-доступ в нём — в планах.
