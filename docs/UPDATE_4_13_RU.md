# ПТО 4.13.0 — исполнительная документация: теги, акт ревизии, пикеты

## 1. Тег «Фамилия И.О.»
Новый тег **`{КЛИЕНТ_ФАМИЛИЯ_ИО}`** → «Иванов И.И.» — в Монтаже ГСВ, Монтаже ГСН и Проектах ГСВ.
Было и осталось: `{КЛИЕНТ}` — «Иванов Иван Иванович», `{КЛИЕНТ_СОКР}` — «И.И. Иванов». Для заказчика-юрлица тег подставляет краткое наименование организации.
Новые теги появляются сами (вкладка «Шаблоны и теги» → список тегов).

## 2. Акт ревизии технических устройств (Монтаж ГСВ)
У каждого прибора есть свой тег — **модель и заводской номер** одной строкой («G4 ВК, зав. № 123»; если приборов вида несколько — через «; »):

| Прибор | Тег | Короткий тег |
|---|---|---|
| Счётчик газа | `{СЧЁТЧИК_ГАЗА}` | `{СЧЕТЧИК}` |
| Сигнализатор | `{СИГНАЛИЗАТОР}` | — |
| Регулятор давления газа | `{РЕГУЛЯТОР_ДАВЛЕНИЯ_ГАЗА}` | `{РЕГУЛЯТОР}` |

Раздельно: `{…_МОДЕЛЬ}` и `{…_СЕРИЙНЫЙ_НОМЕР}`. Теги есть и у остальных видов оборудования (Котёл, Колонка, ПГ).

**Если прибора в объекте нет**, в готовом документе его тег остаётся пустым, а **вся строка удаляется** — вместе с цифрой и названием перед тегом («3 Регулятор {РЕГУЛЯТОР}» исчезает целиком). Это работает для обычных строк и для строк таблицы (таблица удаляется целиком, если не осталось строк). Действует в документах «Акт ревизии тех.устройств» и «Акт о проведении ревизии оборудования»; в остальных документах строки не удаляются.
Правила: строка удаляется, только если пусты **все** теги в ней; строка, где рядом заполнен другой тег, остаётся (на месте пустого тега — пусто). Нумерация, набранная вручную цифрами, **не пересчитывается** (если нет счётчика, строки «2», «3» останутся с этими номерами); автоматическая нумерация Word (список) пересчитывается сама.

## 3. Пикеты в Монтаже ГСН
Новая вкладка карточки **«Пикеты»**: таблица — название (ПК0, ПК1+50…), расстояние от начала трассы, м, примечание. Кнопки «Добавить пикет», «Добавить несколько…» (ПК0, ПК1… с шагом в метрах), «Удалить», «Вверх/Вниз». Сохраняются вместе с договором.
Теги каждого пикета (не меньше 40, при большем числе пикетов — столько, сколько введено):
* `{ПИКЕТ_1}`, `{ПИКЕТ_2}`, … — название;
* `{ПИКЕТ_1_РАССТОЯНИЕ}`, … — расстояние, м;
* `{ПИКЕТ_1_ПРИМЕЧАНИЕ}`, … — примечание;
* `{ПИКЕТЫ}` — все названия по строкам, `{ПИКЕТОВ_ВСЕГО}` — количество.

Если пикетов меньше, чем тегов в шаблоне, строка с лишним тегом пикета **удаляется** из готового документа (во всех документах ГСН) — так же, как в акте ревизии.
