# Три раздела договоров и раздел «Проекты ГСВ» (версия 2.5)

## Три раздела

| Раздел | Меню | Папка договора |
|---|---|---|
| Монтаж ГСВ | «Монтаж ГСВ» | выбирается кнопкой «Папка договора»; по умолчанию предлагается `projects/Монтаж ГСВ` |
| Монтаж ГСН | «Монтаж ГСН» | выбирается кнопкой «Папка договора»; по умолчанию предлагается `projects/Монтаж ГСН` |
| Проекты ГСВ | «Проекты ГСВ» | выбирается кнопкой «Папка договора»; по умолчанию предлагается `projects/Проекты ГСВ` |

Каталог `projects` лежит в папке данных программы. У разделов разные договоры, акты, шаблоны, теги и настройки. Общий у них только клиент.

Правила, одинаковые для всех трёх разделов:

- **Календарь.** Дата договора отмечается на экране «Сегодня»: «Заключение договора Иванов И.И.». Если договор на проект ещё не подписан, добавляется пометка «(не подписан)». Акты и оплаты тоже отмечаются.
- **Клиент.** В «Клиенты» хранятся только личные данные: ФИО, паспорт, дата выдачи, кем выдан, телефоны, адрес. Кнопка «Выбрать из «Клиенты»…» подставляет данные существующего клиента. Если ввести ФИО, которое уже есть, программа предложит подставить сохранённые данные.
- **Блокировка.** При первом создании договора все поля открыты. Потом карточка открывается закрытой; поля разблокирует кнопка «Изменить», а «Сохранить» снова закрывает.
- **Папка.** Автоматически папки не создаются. Кнопка «Папка договора» спрашивает: «Создать новую» или «Привязать существующую…». Новая папка называется `номер ПД - адрес объекта (ФИО клиента)` (для монтажа — номер договора вместо номера ПД); место создания вы выбираете сами. Если адрес объекта не заполнен, берётся адрес клиента, затем наименование объекта. Когда папка привязана, кнопка её открывает; «Сменить папку…» привязывает другую.
- **Файлы клиента.** «Клиенты» → открыть клиента → вкладка «Файлы договоров»: файлы папок всех его договоров, двойной щелчок открывает файл.

## Проекты ГСВ

**Номера** присваиваются сами: номер ПД вида `01-26 ГСВ`, номер договора `01-03/26` (порядковый номер, раздел 03, год). Стоимость по умолчанию 250 BYN, вводится вручную.

**Сроки.** Дата заключения и флажок «Договор подписан». Срок исполнения по умолчанию на 30 дней позже даты заключения; вручную изменённый срок программа больше не двигает. Дата акта и флажок «Акт подписан»: пока акт не подписан, работа считается не сданной. Такие проекты попадают в «Горящие сроки», когда срок близко или прошёл.

**Клиент.** Несколько телефонов, у каждого пояснение («основной», «жена»). Паспорт, кем выдан, дата выдачи, адрес.

**Статусы.** На проекте можно отметить несколько статусов работы (не сделано, в работе, не хватает данных, сделано) и несколько статусов клиента (договор не подписан, договор подписан, акт подписан, передано клиенту, не оплачено, оплачено). Кнопка «Редактор статусов…» (и «Статусы…» в реестре) добавляет, переименовывает, перекрашивает и упорядочивает статусы. Используемый статус удалить нельзя.

**Оплаты.** Кнопка «Оплаты» в карточке: дата, сумма, примечание, остаток по договору.

**Документы по тегам.** В карточке блок «Документы по тегам»: договор (Word), акт (Word), карточка клиента (Excel). Файлы создаются в папке договора. Если после создания изменились данные договора или оплаты, документ получает пометку «данные изменились — переформируйте» и кнопку «⟳ Переформировать».

Шаблоны выбираются на вкладке «Шаблоны и теги» или кнопкой «Шаблоны документов» в реестре; без выбора используются стандартные. Теги записываются в фигурных скобках, регистр и пробелы не важны (`{ДАТА ВЫДАЧИ}` = `{дата_выдачи}`):

`{НОМЕР_ДОГОВОРА}` `{НОМЕР_ПД}` `{ДАТА_ЗАКЛЮЧЕНИЯ_П}` `{ДАТА_ЗАКЛЮЧЕНИЯ_С}` `{СРОК_ИСПОЛНЕНИЯ_П}` `{СРОК_ИСПОЛНЕНИЯ_С}` `{ДАТА_АКТА_П}` `{ДАТА_АКТА_С}` `{КЛИЕНТ}` `{КЛИЕНТ_СОКР}` `{СТОИМОСТЬ}` `{СУММА_ПРОПИСЬЮ}` `{ТЕЛЕФОН}` `{ПАСПОРТ}` `{ДАТА_ВЫДАЧИ}` `{КЕМ_ВЫДАН}` `{АДРЕС_КЛИЕНТА}` `{ОБЪЕКТ}` `{ПРИМЕЧАНИЕ}` `{СТАТУС_КЛИЕНТА}` `{ДАТА_ОПЛАТЫ}` `{СУММА_ОПЛАТЫ}` `{ПРИМЕЧАНИЕ_ОПЛАТЫ}`

Дополнительно: `{АДРЕС_ОБЪЕКТА}`, `{СТАТУС_РАБОТЫ}`, `{ДОГОВОР_ПОДПИСАН}`, `{АКТ_ПОДПИСАН}`, `{ОПЛАЧЕНО}`, `{ОСТАТОК}`. Суффикс `_П` — дата прописью месяца («12 ноября 2026г.»), `_С` — числом («12.11.2026г.»). `{КЛИЕНТ_СОКР}` даёт инициалы и фамилию («И.И. Иванов»). Теги прежнего шаблона (`{ЗАКАЗЧИК}`, `{АДРЕС}` и т. п.) продолжают работать.

**Оплаты в Excel.** В карточке клиента теги `{ДАТА_ОПЛАТЫ}`, `{СУММА_ОПЛАТЫ}`, `{ПРИМЕЧАНИЕ_ОПЛАТЫ}` размножаются вправо: на каждую оплату добавляется блок столбцов той же ширины. В Word эти теги перечисляют все оплаты по строкам.

## Реестр проектов: порядок и дерево статусов

- Реестр всегда упорядочен по номеру ПД (сначала год, затем порядковый номер). Кнопка «№ ПД ↓/↑» меняет направление: новые или старые сверху. Поиск работает по № ПД, объекту и заказчику.
- Слева — дерево статусов: «Статус работы» и «Статус клиента» → статус с числом проектов → проекты (по порядку № ПД). Нажмите на статус, например «Акт подписан» — раскроется список проектов с этим статусом; двойной щелчок по проекту открывает договор. «Свернуть всё» сворачивает дерево; «◀ Скрыть» или кнопка «Дерево статусов» в панели прячут и возвращают его (выбор запоминается). Поле над деревом ищет проект по № ПД или заказчику.
- Папки, созданные программой автоматически в прошлых версиях и оставшиеся пустыми, при обновлении отвязываются и удаляются; папки с файлами и ваши собственные не затрагиваются.

## Графа «ТУ»

В блоке «Объект проектирования» есть поле «ТУ»: номер и дата технических условий, выданных клиенту (например, «№ 123 от 01.02.2026»). Тег для шаблонов — `{ТУ}`, графа есть и в выгрузке в Excel.

## Импорт договоров из Excel

В реестре «Проекты ГСВ» кнопка **«Импорт из Excel…»**.

1. Выберите файл. Строка заголовков находится сама (даже если над таблицей есть название), столбцы подбираются по названиям.
2. В таблице привязки каждому столбцу назначена графа карточки договора; любую привязку можно поменять или отключить («— не импортировать —»). Одна графа не может быть назначена двум столбцам.
3. Нажмите «Проверить»: для каждой строки показан результат — «Новый», «Уже есть» (такой № ПД уже в программе) или «Ошибка» (нет заказчика, не распознан или повторяется № ПД; такие строки пропускаются). Нераспознанные дата или стоимость — только замечание, строка импортируется без этого значения.
4. Выберите, что делать с уже существующими № ПД: пропустить или обновить, и нажмите «Импортировать».

Привязка по умолчанию: № ПД → номер ПД, Наименование объекта строительства → объект, Адрес → адрес клиента, Заказчик → клиент, Телефон → телефон, Паспортные данные → паспорт, № договора → номер договора, Дата заключения, Дата акта, Стоимость, Срок выполнения, ТУ → одноимённые графы. Столбец «Адрес» можно перенацелить на «Адрес объекта».

Что делает импорт:

- Даты читаются в любом виде: ячейка-дата Excel, `12.11.2026`, `12 ноября 2026г.`. Стоимость: `250`, `1 250,50`, `320,50 руб.`.
- № ПД вида `1-26` приводится к `01-26 ГСВ`. Если номер договора пуст, он строится из № ПД (`01-03/26`). Если пуст № ПД, присваивается следующий свободный.
- Заказчик ищется в «Клиенты» по ФИО (без учёта регистра и лишних пробелов). Найденный клиент используется повторно, его заполненные данные не затираются; новый создаётся с телефоном, адресом и паспортом.
- Пустой срок выполнения = дата заключения + 30 дней. Пустая стоимость = 250.
- Если дата заключения есть, договор отмечается подписанным; если есть дата акта, подписанным отмечается и акт. Галочка «Проставить статусы по датам» добавляет статусы «Договор подписан» или «Акт подписан» и «Сделано».
- Папки при импорте не создаются; договоры появляются в календаре.

## Автоматическая выгрузка в Excel

Раз в час, пока программа запущена, перезаписываются два файла в папке данных `excel_reports`:

- `Проекты_ГСВ_карточки.xlsx` — все карточки договоров на проекты (клиент, паспорт, сроки, подписи, статусы, оплаты, остаток, папка);
- `Реестры_договоров.xlsx` — монтаж ГСВ и монтаж ГСН.

Состояние и кнопка «Обновить сейчас» — в «Настройках». Полные резервные копии программы делаются как раньше.

## Обновление существующих баз

Схема обновляется сама. Прежние статусы переносятся: «Сделано» → «Сделано», «Подписан» → «Договор подписан», «Оплачен» → «Оплачено»; «Подписан» у договора и дата акта дают флажки подписания. Старые папки проектов сохраняются.
