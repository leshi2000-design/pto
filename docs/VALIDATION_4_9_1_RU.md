# Проверка ПТО 4.9.1

Проверены исходники из PTO_4.9.0.zip после исправления девяти пунктов аудита.

- Полный прогон: **366 passed, 4 skipped**, 118,59 секунды.
- Новые регрессионные сценарии: **42 passed** (включены в полный прогон).
- Команда: `python -m pytest tests -q --durations=10`.
- Среда: Python 3.12.14, Linux, Qt offscreen; PyQt6 6.11.0, Qt 6.11.0.
- Зависимости из requirements-tested.txt; pytest установлен отдельно.
- Все модули smetagaz/*.py проверены синтаксическим разбором.
- Windows EXE и установщик не собирались и не проверялись.

Проверки на настоящем HTTPS подтверждают запрет чужих SAVEPOINT, отзыв сеансов
с откатом транзакции, блокировку служебных PRAGMA и записей журнала, разделение
настроек и чтение оплат наблюдателем. Проверка потерянного ответа применяет запись
на настоящем серверном обработчике и искусственно теряет ответ транспорта;
результат — одна строка и одна отправка. Восстановление проверено после удаления
исходных внешних папок документов, в новую папку.

## Нагрузочная проверка

`python tests/benchmark.py`: 100 000 материалов и импорт 1 000 небольших файлов.
Синтетические данные, один локальный запуск; это не прогноз скорости офисной сети.

```json
{
  "records": 100000,
  "files_imported": 1000,
  "file_import_seconds": 0.143,
  "insert_seconds": 2.185,
  "search_avg_ms": 8.343,
  "page_ms": 0.136,
  "backup_seconds": 0.514,
  "restore_seconds": 0.552,
  "database_bytes": 38727680
}
```

Предупреждения полного прогона: устаревающий datetime.utcnow() при создании
сертификата и предупреждение стороннего pytest-плагина; ошибок тестов нет.
Четыре пропуска — OCR-проверки, которым нужен установленный Tesseract с русским
языковым пакетом. Эта возможность в среде не установлена. Не все прикладные
тесты выполнялись по сети: сетевой слой проверялся собственными HTTPS-тестами
штатного и нового наборов.
