# ПТО 4.9.5 — обновление программы одним ZIP-файлом (без замены файлов) и надёжное закрытие

## Как обновлять теперь
1. Получите ZIP-архив новой версии (тот же файл, что присылается для установки, например `PTO_4.9.6.zip`).
2. В программе: **Справка (F1) → «Обновить программу из ZIP…»** (или **Настройки → «Обновить программу из ZIP…»**) → **«Выбрать ZIP…»** → подтвердите.
3. Программа сама:
   * проверит архив (это действительно обновление ПТО; безопасные пути; нет исполняемых файлов; размер),
   * распакует его **в папку данных** (`C:\Users\<имя>\.smetagaz\updates\v<версия>_<время>`),
   * проверит синтаксис и **запустит самопроверку нового кода в отдельном процессе** (пустая база во временной папке, открываются все разделы меню),
   * сделает снимок баз данных (`backups\before_update_…`),
   * включит обновление.
4. Закройте программу и откройте снова — запустится новая версия (база обновится сама).

**Файлы программы (`PTO.exe`, `_internal`) не заменяются** — нет блокировок Windows, «полузамененных» файлов и перемешивания старых и новых модулей. Папку программы после этого заменять не нужно.

## Если что-то пошло не так
* Самопроверка не пройдена → обновление **не устанавливается**, программа работает как раньше; в окне виден отчёт.
* Новая версия установилась, но не запускается → при запуске программа **сама отключает её** (причина — `updates\last_failure.txt`) и стартует со встроенной версией.
* Вручную: в том же окне **«Вернуться к встроенной версии»**; установленные обновления перечислены в окне (хранятся 3 последних, включённое — всегда).
* Встроенная версия не меняется; если она новее обновления (например, вы пересобрали программу), обновление игнорируется.
* Обновление может менять только код и данные программы (папка `smetagaz`). Если новая версия требует **новых библиотек**, программа предупредит — тогда нужна обычная пересборка (`build_windows.bat`).
* Запуск «в обход» обновления: переменная окружения `PTO_NO_OVERLAY=1`.

## ВАЖНО: один раз нужна пересборка
Чтобы ZIP-обновления заработали, в программу должен быть встроен небольшой загрузчик (`pto_overlay.py`) — он появился в этой версии. Поэтому **ПТО 4.9.5 нужно один раз установить как раньше** (собрать `build_windows.bat` из этого ZIP и запускать новый `PTO.exe`). Начиная с неё все следующие версии ставятся через «Обновить программу из ZIP…».

## Зависания при закрытии (исправлено)
Причина: при закрытии программа **дожидалась окончания фоновой копии** (полной копии с гигабайтами вложений, выгрузки, внешней копии) — окно висело «не отвечает», приходилось завершать процесс в диспетчере задач. Теперь:
* идущие фоновые копии при закрытии **прерываются на ближайшем файле** (временные файлы удаляются, готовые копии не затрагиваются);
* копия при закрытии не стоит в очереди за долгой полной копией;
* ожидание завершения ограничено (до 8 с), а если процесс всё же не завершился за 15 с, он **завершается принудительно** (данные не страдают: база записывается транзакциями).
