# ПТО 4.9.2 — «Сохранить как» перед формированием документов

При ручном создании или переформировании документа программа предлагает:

1. Выбрать папку сохранения.
2. Оставить стандартное имя или ввести своё.
3. Нажать «Сохранить» либо отменить действие.

Расширение соответствует формату результата. Например: «Договор_01-02-26.docx».
Если шаблон Excel, предлагается .xlsx, даже когда вид документа — договор или акт.
При существующем файле окно спрашивает о замене. Исходный шаблон нельзя выбрать
в качестве выходного документа. Выбранный путь записывается в карточку документа:
«Открыть», «Печать» и последующие резервные копии учитывают новый путь.

## Где действует

- Договоры, акты, справки и карточки в «Монтаж ГСВ», «Монтаж ГСН», «Проекты ГСВ».
- Документы юридических лиц, СМР, ТО, ИП и физических лиц.
- Наряды и наряды-допуски, из карточки и из реестра.
- Исполнительная документация, включая «Сформировать все», индивидуальные шаблоны
  и комплекты ИД. Для каждого создаваемого файла предлагается отдельное имя и путь.
- Ручная выгрузка реестров и карточек проектов из настроек — два окна для двух файлов.

Сметы, универсальные экспорты Word/Excel/PDF, ведомости и отчёты, которые уже
предлагали «Сохранить как», сохраняют этот порядок. Печать на принтер, открытие
готового файла, импорт и внутреннее создание типового шаблона не являются
формированием нового пользовательского документа.

Сначала можно выбрать папку договора как раньше — она будет предложена при
сохранении. Привязывать папку договора ради одного документа теперь необязательно.
Если подходящей папки нет, окно открывается в «Документах» или в последней
выбранной за текущий запуск папке.

## Комплекты документов

В комплектах ИД все пути выбираются в основном потоке интерфейса до запуска
формирования. Если отменить любое окно выбора, не будет создан ни один файл
этого комплекта. Нельзя указать один и тот же путь для двух разных документов.

Можно сохранить файлы в разных папках и на разных дисках. Для каждого назначения
временный файл создаётся рядом с результатом. При ошибке формирования или записи
истории выполняется откат уже заменённых файлов. Прежние файлы по другим путям
не удаляются. В комплекте ИД итоговые пути видны во вкладке «История файлов».

Кнопка «Сформировать все» во вкладках документов ГСВ/ГСН работает последовательно:
каждый документ имеет своё окно. При отмене дальнейшее формирование останавливается;
документы, уже подтверждённые и созданные до отмены, сохраняются.

Автоматические почасовые выгрузки и резервные копии продолжают работать в фоне
по настроенным путям, без появления окон выбора во время работы пользователя.

## Обновление

Распакуйте новую версию отдельно от прежней, сохранив резервную копию рабочих
данных. Протокол остаётся 2, схема документов не меняется. Сетевая версия
совместима с сервером 4.9.1. Папка данных и существующие документы сохраняются.

В архиве исходники, а не готовая Windows EXE. Сборка: `build_windows.bat server`.
Внесённые ранее исправления безопасности 4.9.1 сохранены.

Проверки добавлены в `tests/test_document_save_492.py`: окно и стандартное имя,
переименование и расширение, отмена, защита шаблона, ссылки карточек на выбранные
файлы, комплекты в разных папках и откат при ошибке записи истории.
