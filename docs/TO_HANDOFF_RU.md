# Кнопка «Передать в ТО» (Монтаж ГСВ → «ТО физ.лиц.»)

В карточке договора **«Монтаж ГСВ»**, внизу, рядом с «Скопировать данные клиента» появилась кнопка **«Передать в ТО»**.
Она одним нажатием отправляет данные в программу **«ТО физ.лиц.»**, которая работает на этом же компьютере.

## Что передаётся
- **Клиент:** ФИО, телефон(ы), адрес, паспорт (серия, номер и личный номер, если он вписан в то же поле), кем выдан, дата выдачи.
- **Адрес объекта** (адрес установки газового оборудования).
- **Газовое оборудование:** вид (Котёл, Колонка, ПГ), модель и **серийный номер**.
- Номер договора монтажа — для справки (попадает в примечание договора ТО).

Передаются данные из карточки **в том виде, как они сейчас на экране**, — сохранять договор в ПТО перед этим не нужно.

## Что произойдёт
1. Если в карточке ровно один котёл, колонка или газовая плита — он передаётся сразу. Если оборудования несколько (или нет
   подходящего), откроется короткое окно: отметьте, на что нужен договор технического обслуживания. Счётчики, сигнализаторы и
   регуляторы по умолчанию не отмечены. На каждое отмеченное оборудование в «ТО физ.лиц.» откроется отдельная карточка.
2. Если «ТО физ.лиц.» уже запущена, карточка нового договора откроется там сама через пару секунд (окно выйдет на передний
   план или замигает на панели задач). Если она закрыта — ПТО её запустит. При первой передаче, если ПТО не знает, где лежит
   `TO_fizlic.exe`, она попросит указать этот файл один раз и запомнит.
3. В карточке «ТО физ.лиц.» уже заполнены клиент, паспортные данные, адрес установки, наименование оборудования, серийный
   номер; тип оборудования подобран из справочника по виду (котёл → «Котёл …»), от него подставится стоимость ТО.
   Остаётся ввести **номер и дату договора** и нажать «Сохранить и сформировать документы».
4. Если такой клиент уже есть в «ТО физ.лиц.» (по паспорту, а без него — по ФИО и телефону), новый не создаётся: берётся
   существующий. Если у него уже есть договор ТО на оборудование с тем же серийным номером, программа спросит, открыть
   существующий или всё равно создать новый.

## Ограничения
- Заказчик — **юридическое лицо**: кнопка откажет (ТО физ.лиц. работает только с физическими лицами).
- Обмен идёт через папку `%APPDATA%\TO_fizlic\inbox` текущего пользователя Windows: обе программы должны быть запущены
  под одной и той же учётной записью.
- В обратную сторону (из «ТО физ.лиц.» в ПТО) данные не передаются. ПТО «ТО физ.лиц.» ничего не меняет в своей базе —
  только отправляет файл.
- Если «ТО физ.лиц.» заблокирована паролем, карточка откроется после разблокировки.

Технически: ПТО пишет файл `pto_*.json` в `inbox` (формат — в модуле `handoff` программы «ТО физ.лиц.»), «ТО физ.лиц.»
забирает его, обрабатывает и перекладывает в `inbox\done` (последние 20) или `inbox\bad` с описанием ошибки.
